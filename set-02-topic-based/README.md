# Topic-Based React Practice Tasks

This project contains React practice tasks organized according to Brian Holt's React v9 course structure from Frontend Masters. Tasks are grouped by specific React concepts and topics.

## Topics Covered

- **Basic Components**: Component basics and composition
- **JSX**: JSX syntax, expressions, and conditional rendering
- **Hooks**: useState, useEffect, and custom hooks
- **Context API**: Context creation and consumption
- **React Ecosystem**: Routing and data fetching
- **Advanced React**: Portals, error boundaries, and uncontrolled forms
- **Testing**: Component and hook testing approaches
- **React Render Modes**: Understanding render behavior
- **React Server Components**: Client vs server components
- **Performance Optimizations**: Memoization and code splitting
- **Transitions**: Concurrent rendering features
- **Optimistic Updates**: Handling optimistic UI patterns
- **Deferred Values**: Performance optimization with deferred values

## Implementation Guidelines

1. Each task focuses on a specific React concept or feature
2. Mock data is used instead of real backend services
3. Comments explain the implementation and key concepts
4. TypeScript is used for improved type safety
