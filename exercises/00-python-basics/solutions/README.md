# Solutions Folder - Python Basics (Day 0)

Save your completed Day 0 exercise solutions here.

## Naming Convention

- `exercise_1_solution.py` - FizzBuzz
- `exercise_2_solution.py` - Palindrome Checker
- `exercise_3_solution.py` - Word Frequency Counter
- ... and so on

## How to Use

1. Complete an exercise in the parent directory (e.g., `exercise_1.py`)
2. Test it thoroughly
3. Once working, copy it here:
```bash
   cp exercise_1.py solutions/exercise_1_solution.py
```
