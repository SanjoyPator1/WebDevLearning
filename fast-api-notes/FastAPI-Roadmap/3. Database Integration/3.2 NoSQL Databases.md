# 3.2 NoSQL Databases in FastAPI

## Overview

NoSQL databases offer flexibility, scalability, and performance benefits for modern applications. FastAPI integrates well with various NoSQL databases through async drivers and ORMs, making it ideal for high-performance applications.

## Types of NoSQL Databases

### Document Databases

- **MongoDB**: Most popular document database
- **CouchDB**: HTTP-based document storage
- **Amazon DocumentDB**: MongoDB-compatible service

### Key-Value Stores

- **Redis**: In-memory data structure store
- **Amazon DynamoDB**: Serverless key-value database
- **Cassandra**: Wide-column store

### Graph Databases

- **Neo4j**: Property graph database
- **Amazon Neptune**: Managed graph database
- **ArangoDB**: Multi-model database

### Time-Series Databases

- **InfluxDB**: Time-series data platform
- **TimescaleDB**: PostgreSQL extension for time-series

### Document Models with Beanie

```python
# models.py
from beanie import Document, Indexed
from pydantic import Field, EmailStr
from typing import Optional, List
from datetime import datetime
from enum import Enum

class UserStatus(str, Enum):
    ACTIVE = "active"
    INACTIVE = "inactive"
    BANNED = "banned"

class User(Document):
    email: Indexed(EmailStr, unique=True)
    name: str
    age: Optional[int] = Field(None, ge=0, le=120)
    status: UserStatus = UserStatus.ACTIVE
    tags: List[str] = Field(default_factory=list)
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)

    class Settings:
        collection = "users"
        indexes = [
            "email",
            "status",
            "created_at",
            [("name", 1), ("status", 1)]  # Compound index
        ]

class Post(Document):
    title: str
    content: str
    author_id: str
    tags: List[str] = Field(default_factory=list)
    likes: int = Field(default=0, ge=0)
    published: bool = Field(default=False)
    created_at: datetime = Field(default_factory=datetime.utcnow)

    class Settings:
        collection = "posts"
```

### FastAPI Application Setup

```python
# main.py
from fastapi import FastAPI
from contextlib import asynccontextmanager
from beanie import init_beanie
from database import connect_to_mongo, close_mongo_connection, db
from models import User, Post

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup
    await connect_to_mongo()
    await init_beanie(database=db.database, document_models=[User, Post])
    yield
    # Shutdown
    await close_mongo_connection()

app = FastAPI(lifespan=lifespan)
```

### CRUD Operations with MongoDB

```python
# crud.py
from beanie import PydanticObjectId
from models import User, Post
from schemas import UserCreate, UserUpdate
from typing import List, Optional

class UserCRUD:
    @staticmethod
    async def create(user_data: UserCreate) -> User:
        user = User(**user_data.dict())
        await user.insert()
        return user

    @staticmethod
    async def get_by_id(user_id: PydanticObjectId) -> Optional[User]:
        return await User.get(user_id)

    @staticmethod
    async def get_by_email(email: str) -> Optional[User]:
        return await User.find_one(User.email == email)

    @staticmethod
    async def get_all(skip: int = 0, limit: int = 100) -> List[User]:
        return await User.find_all().skip(skip).limit(limit).to_list()

    @staticmethod
    async def update(user_id: PydanticObjectId, user_data: UserUpdate) -> Optional[User]:
        user = await User.get(user_id)
        if user:
            update_data = user_data.dict(exclude_unset=True)
            update_data["updated_at"] = datetime.utcnow()
            await user.update({"$set": update_data})
            return user
        return None

    @staticmethod
    async def delete(user_id: PydanticObjectId) -> bool:
        user = await User.get(user_id)
        if user:
            await user.delete()
            return True
        return False

# Advanced queries
class UserQueries:
    @staticmethod
    async def search_by_name(name: str) -> List[User]:
        return await User.find({"name": {"$regex": name, "$options": "i"}}).to_list()

    @staticmethod
    async def get_active_users() -> List[User]:
        return await User.find(User.status == "active").to_list()

    @staticmethod
    async def get_users_by_age_range(min_age: int, max_age: int) -> List[User]:
        return await User.find({"age": {"$gte": min_age, "$lte": max_age}}).to_list()
```

### FastAPI Endpoints

```python
@app.post("/users", response_model=User)
async def create_user(user: UserCreate):
    existing_user = await UserCRUD.get_by_email(user.email)
    if existing_user:
        raise HTTPException(status_code=400, detail="Email already registered")
    return await UserCRUD.create(user)

@app.get("/users/{user_id}", response_model=User)
async def get_user(user_id: PydanticObjectId):
    user = await UserCRUD.get_by_id(user_id)
    if not user:
        raise HTTPException(status_code=404, detail="User not found")
    return user

@app.get("/users/search/{name}", response_model=List[User])
async def search_users(name: str):
    return await UserQueries.search_by_name(name)
```

```python
# redis_client.py
import redis.asyncio as redis
import json
from typing import Any, Optional
import os

class RedisClient:
    def __init__(self):
        self.redis = None

    async def connect(self):
        self.redis = redis.from_url(
            os.getenv("REDIS_URL", "redis://localhost:6379"),
            encoding="utf-8",
            decode_responses=True
        )

    async def disconnect(self):
        if self.redis:
            await self.redis.close()

    async def set(self, key: str, value: Any, expire: int = None):
        serialized_value = json.dumps(value) if not isinstance(value, str) else value
        await self.redis.set(key, serialized_value, ex=expire)

    async def get(self, key: str) -> Optional[Any]:
        value = await self.redis.get(key)
        if value:
            try:
                return json.loads(value)
            except json.JSONDecodeError:
                return value
        return None

    async def delete(self, key: str):
        await self.redis.delete(key)

    async def exists(self, key: str) -> bool:
        return await self.redis.exists(key)

redis_client = RedisClient()
```

### Caching Patterns

```python
# cache.py
from functools import wraps
from redis_client import redis_client
import hashlib

def cache_result(expire: int = 300):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            # Create cache key from function name and arguments
            cache_key = f"{func.__name__}:{hashlib.md5(str(args + tuple(kwargs.items())).encode()).hexdigest()}"

            # Try to get from cache
            cached_result = await redis_client.get(cache_key)
            if cached_result:
                return cached_result

            # Execute function and cache result
            result = await func(*args, **kwargs)
            await redis_client.set(cache_key, result, expire=expire)
            return result

        return wrapper
    return decorator

# Usage example
@cache_result(expire=600)  # Cache for 10 minutes
async def get_user_posts(user_id: str):
    return await Post.find({"author_id": user_id}).to_list()
```

### Session Management

```python
# sessions.py
import uuid
from datetime import datetime, timedelta
from redis_client import redis_client

class SessionManager:
    @staticmethod
    async def create_session(user_id: str, expire_hours: int = 24) -> str:
        session_id = str(uuid.uuid4())
        session_data = {
            "user_id": user_id,
            "created_at": datetime.utcnow().isoformat(),
            "expires_at": (datetime.utcnow() + timedelta(hours=expire_hours)).isoformat()
        }

        await redis_client.set(
            f"session:{session_id}",
            session_data,
            expire=expire_hours * 3600
        )
        return session_id

    @staticmethod
    async def get_session(session_id: str) -> Optional[dict]:
        return await redis_client.get(f"session:{session_id}")

    @staticmethod
    async def delete_session(session_id: str):
        await redis_client.delete(f"session:{session_id}")
```

# dynamodb.py
import boto3
from boto3.dynamodb.conditions import Key, Attr
import os

class DynamoDBClient:
    def __init__(self):
        self.dynamodb = boto3.resource(
            'dynamodb',
            region_name=os.getenv('AWS_REGION', 'us-east-1'),
            aws_access_key_id=os.getenv('AWS_ACCESS_KEY_ID'),
            aws_secret_access_key=os.getenv('AWS_SECRET_ACCESS_KEY')
        )
        self.table = self.dynamodb.Table('users')

    async def create_item(self, item: dict):
        return self.table.put_item(Item=item)

    async def get_item(self, key: dict):
        response = self.table.get_item(Key=key)
        return response.get('Item')

    async def query_items(self, partition_key: str, partition_value: str):
        response = self.table.query(
            KeyConditionExpression=Key(partition_key).eq(partition_value)
        )
        return response['Items']

    async def scan_items(self, filter_expression=None):
        if filter_expression:
            response = self.table.scan(FilterExpression=filter_expression)
        else:
            response = self.table.scan()
        return response['Items']

# neo4j_client.py
from neo4j import GraphDatabase
import os

class Neo4jClient:
    def __init__(self):
        self.driver = GraphDatabase.driver(
            os.getenv("NEO4J_URI", "bolt://localhost:7687"),
            auth=(
                os.getenv("NEO4J_USER", "neo4j"),
                os.getenv("NEO4J_PASSWORD", "password")
            )
        )

    def close(self):
        self.driver.close()

    async def create_user(self, name: str, email: str):
        with self.driver.session() as session:
            result = session.run(
                "CREATE (u:User {name: $name, email: $email}) RETURN u",
                name=name, email=email
            )
            return result.single()

    async def create_friendship(self, user1_id: str, user2_id: str):
        with self.driver.session() as session:
            session.run(
                """
                MATCH (u1:User {id: $user1_id}), (u2:User {id: $user2_id})
                CREATE (u1)-[:FRIEND]->(u2)
                """,
                user1_id=user1_id, user2_id=user2_id
            )

    async def get_friends(self, user_id: str):
        with self.driver.session() as session:
            result = session.run(
                """
                MATCH (u:User {id: $user_id})-[:FRIEND]->(friend:User)
                RETURN friend
                """,
                user_id=user_id
            )
            return [record["friend"] for record in result]

neo4j_client = Neo4jClient()
```

from influxdb_client.client.influxdb_client_async import InfluxDBClientAsync
from influxdb_client import Point
from datetime import datetime
import os

class InfluxDBClient:
    def __init__(self):
        self.client = InfluxDBClientAsync(
            url=os.getenv("INFLUXDB_URL", "http://localhost:8086"),
            token=os.getenv("INFLUXDB_TOKEN"),
            org=os.getenv("INFLUXDB_ORG", "my-org")
        )
        self.bucket = os.getenv("INFLUXDB_BUCKET", "my-bucket")

    async def write_metric(self, measurement: str, tags: dict, fields: dict):
        write_api = self.client.write_api()
        point = Point(measurement)

        for key, value in tags.items():
            point = point.tag(key, value)

        for key, value in fields.items():
            point = point.field(key, value)

        point = point.time(datetime.utcnow())

        await write_api.write(bucket=self.bucket, record=point)

    async def query_metrics(self, query: str):
        query_api = self.client.query_api()
        result = await query_api.query(query)
        return result

influx_client = InfluxDBClient()
```

## NoSQL Best Practices

### Data Modeling

- **Denormalization**: Store related data together for read performance
- **Embedding vs Referencing**: Choose based on access patterns
- **Schema Design**: Design for your query patterns, not normalization
- **Indexing Strategy**: Create indexes for frequently queried fields

### Query Optimization

- **Projection**: Only fetch required fields
- **Pagination**: Implement proper pagination for large datasets
- **Aggregation**: Use database aggregation features when possible
- **Connection Pooling**: Manage database connections efficiently

### Consistency Patterns

- **Eventual Consistency**: Accept temporary inconsistency for performance
- **Strong Consistency**: Use when data accuracy is critical
- **Conflict Resolution**: Handle concurrent updates appropriately
- **Transaction Support**: Use transactions when available and needed

## Error Handling and Validation

### Connection Management

```python
# error_handling.py
from fastapi import HTTPException
import logging

async def handle_database_error(operation, *args, **kwargs):
    try:
        return await operation(*args, **kwargs)
    except ConnectionError:
        logging.error("Database connection failed")
        raise HTTPException(status_code=503, detail="Database unavailable")
    except Exception as e:
        logging.error(f"Database operation failed: {str(e)}")
        raise HTTPException(status_code=500, detail="Internal server error")
```

### Data Validation

- **Schema Validation**: Use Pydantic models for input validation
- **Business Rules**: Implement custom validation logic
- **Constraint Enforcement**: Use database constraints when available
- **Error Recovery**: Implement retry logic for transient failures

## Performance Considerations

### MongoDB Performance

- **Index Usage**: Monitor query execution plans
- **Connection Pooling**: Configure appropriate pool sizes
- **Read Preferences**: Use secondary reads when appropriate
- **Sharding**: Implement sharding for large datasets

### Redis Performance

- **Memory Management**: Monitor memory usage and implement eviction policies
- **Pipeline Operations**: Batch operations for better performance
- **Clustering**: Use Redis Cluster for horizontal scaling
- **Persistence**: Choose appropriate persistence strategy

### General NoSQL Performance

- **Caching Layers**: Implement multi-level caching
- **Read Replicas**: Use read replicas to distribute load
- **Data Partitioning**: Partition data based on access patterns
- **Monitoring**: Implement comprehensive monitoring and alerting

## Security Considerations

### Authentication and Authorization

- **Database Authentication**: Use strong authentication mechanisms
- **Role-Based Access**: Implement proper role-based access control
- **Network Security**: Use VPNs or private networks
- **Encryption**: Encrypt data at rest and in transit

### Data Protection

- **Input Sanitization**: Sanitize all user inputs
- **Injection Prevention**: Prevent NoSQL injection attacks
- **Audit Logging**: Log all database operations
- **Backup Security**: Secure database backups

## Key Takeaways

1. **Choose the Right Database** - Select NoSQL type based on your data model and access patterns
2. **Async Operations** - Use async drivers for better performance in FastAPI
3. **Schema Design** - Design for your query patterns, not traditional normalization
4. **Indexing Strategy** - Create appropriate indexes for query performance
5. **Error Handling** - Implement robust error handling for database operations
6. **Caching Patterns** - Use Redis or similar for caching frequently accessed data
7. **Testing Strategy** - Use separate test databases and proper cleanup
8. **Security First** - Implement proper authentication, authorization, and encryption
9. **Performance Monitoring** - Monitor query performance and optimize accordingly
10. **Consistency Model** - Choose appropriate consistency level for your use case
