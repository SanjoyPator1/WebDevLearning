# 8.2 Rate Limiting and Throttling

## Introduction to Rate Limiting

Rate limiting is a technique used to control the amount of incoming and outgoing traffic to or from a network, application, or service. In the context of APIs, rate limiting restricts the number of requests a client can make within a specified time period.

### Why Implement Rate Limiting?

- **Prevent Abuse**: Protect your API from malicious users or accidental misuse
- **Ensure Fair Usage**: Allocate resources equitably among all clients
- **Improve Reliability**: Prevent server overload during traffic spikes
- **Cost Control**: Manage infrastructure costs by controlling request volume
- **Performance Optimization**: Maintain responsive service for all users
- **Security**: Mitigate certain types of attacks (e.g., brute force, DoS)

### Key Rate Limiting Concepts

- **Rate Limit**: Maximum number of requests allowed in a time window
- **Time Window**: Period over which requests are counted (e.g., per second, minute, hour)
- **Burst**: Short-term increase in request rate that may be allowed temporarily
- **Throttling**: Temporarily reducing the rate of requests being processed
- **Quota**: Total number of requests allowed over a longer period (e.g., daily/monthly)

## Implementing Rate Limiting in FastAPI

FastAPI doesn't include built-in rate limiting, but we can implement it using middleware, dependencies, or third-party libraries.

### Basic Rate Limiting with FastAPI Middleware

First, let's create a simple in-memory rate limiter using FastAPI middleware:

```python
from fastapi import FastAPI, Request, HTTPException
from fastapi.middleware.base import BaseHTTPMiddleware
import time
from collections import defaultdict
import asyncio

app = FastAPI()

# Simple in-memory storage for request counts
# In production, use Redis or another distributed cache
class SimpleRateLimiter:
    def __init__(self, requests_per_minute=60):
        self.requests_per_minute = requests_per_minute
        self.request_counts = defaultdict(list)
        self.lock = asyncio.Lock()

    async def is_rate_limited(self, client_ip: str) -> bool:
        async with self.lock:
            # Get current timestamp
            now = time.time()

            # Get request timestamps for this client
            request_times = self.request_counts[client_ip]

            # Remove timestamps older than 1 minute
            self.request_counts[client_ip] = [ts for ts in request_times if ts > now - 60]

            # Check if rate limit is exceeded
            if len(self.request_counts[client_ip]) >= self.requests_per_minute:
                return True

            # Add current request timestamp
            self.request_counts[client_ip].append(now)
            return False

# Create rate limiter instance
rate_limiter = SimpleRateLimiter(requests_per_minute=60)

# Create rate limiting middleware
class RateLimitMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        # Get client IP (in production, consider X-Forwarded-For header)
        client_ip = request.client.host

        # Check if client is rate limited
        is_limited = await rate_limiter.is_rate_limited(client_ip)
        if is_limited:
            return HTTPException(
                status_code=429,
                detail="Too many requests. Please try again later."
            )

        # Process the request normally if not rate limited
        response = await call_next(request)
        return response

# Add middleware to FastAPI app
app.add_middleware(RateLimitMiddleware)

# Regular API endpoints
@app.get("/")
async def root():
    return {"message": "Hello World"}

@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

```

### Using FastAPI Dependencies for Endpoint-Specific Rate Limiting

For more granular control, we can use FastAPI dependencies to apply rate limits to specific endpoints:

```python
from fastapi import FastAPI, Depends, HTTPException, Request
from typing import Callable, Dict, List, Optional
import time
import asyncio

app = FastAPI()

# Rate limiter using dependency injection
class RateLimiter:
    def __init__(
        self,
        times: int = 60,
        seconds: int = 60,
        exempted_paths: List[str] = None
    ):
        self.times = times
        self.seconds = seconds
        self.exempted_paths = exempted_paths or []
        self.requests: Dict[str, List[float]] = {}
        self.lock = asyncio.Lock()

    async def is_rate_limited(self, key: str, path: str) -> bool:
        # Check if path is exempted from rate limiting
        if any(path.startswith(exempted) for exempted in self.exempted_paths):
            return False

        async with self.lock:
            # Initialize if key not seen before
            if key not in self.requests:
                self.requests[key] = []

            # Get current timestamp
            now = time.time()

            # Clean old requests
            self.requests[key] = [
                request_time for request_time in self.requests[key]
                if request_time > now - self.seconds
            ]

            # Check rate limit
            if len(self.requests[key]) >= self.times:
                return True

            # Add current request
            self.requests[key].append(now)
            return False

    # Create a dependency that can be used in FastAPI routes
    def dependency(
        self,
        key_func: Callable[[Request], str] = None
    ) -> Callable:
        async def rate_limit_dependency(request: Request):
            # Default to client IP if no key function provided
            key = key_func(request) if key_func else request.client.host
            path = request.url.path

            # Check if rate limited
            is_limited = await self.is_rate_limited(key, path)
            if is_limited:
                raise HTTPException(
                    status_code=429,
                    detail="Rate limit exceeded. Please try again later.",
                    headers={"Retry-After": str(self.seconds)}
                )

        return rate_limit_dependency

# Create a rate limiter for API endpoints
general_rate_limiter = RateLimiter(
    times=100,          # 100 requests
    seconds=60,         # per minute
    exempted_paths=["/docs", "/openapi.json"]  # Swagger docs exempted
)

# Create a stricter limiter for sensitive endpoints
strict_rate_limiter = RateLimiter(
    times=10,           # 10 requests
    seconds=60          # per minute
)

# Apply different rate limits to different endpoints
@app.get("/public/", dependencies=[Depends(general_rate_limiter.dependency())])
async def public_endpoint():
    return {"message": "This is a public endpoint with standard rate limiting"}

@app.get("/sensitive/", dependencies=[Depends(strict_rate_limiter.dependency())])
async def sensitive_endpoint():
    return {"message": "This is a sensitive endpoint with stricter rate limiting"}

@app.get("/")
async def root():
    return {"message": "This endpoint has no rate limiting"}

```

## Token Bucket Algorithm

The Token Bucket algorithm is one of the most common rate limiting algorithms. It works by:

1. Having a bucket that continuously fills with tokens at a fixed rate
2. Each request consumes one or more tokens from the bucket
3. If the bucket is empty, the request is rejected or delayed
4. The bucket has a maximum capacity to prevent token accumulation

### Implementing Token Bucket in FastAPI

```python
from fastapi import FastAPI, Request, HTTPException, Depends
import time
import asyncio
from typing import Dict, Tuple

app = FastAPI()

class TokenBucket:
    def __init__(self, tokens_per_second: float, max_tokens: float):
        self.tokens_per_second = tokens_per_second
        self.max_tokens = max_tokens
        self.buckets: Dict[str, Tuple[float, float]] = {}  # (tokens, last_refill_time)
        self.lock = asyncio.Lock()

    async def consume(self, key: str, tokens: float = 1.0) -> bool:
        async with self.lock:
            # Initialize bucket if not exists
            if key not in self.buckets:
                self.buckets[key] = (self.max_tokens, time.time())

            # Get current tokens and last refill time
            tokens_in_bucket, last_refill = self.buckets[key]

            # Calculate time passed since last refill
            now = time.time()
            time_passed = now - last_refill

            # Add new tokens based on time passed
            new_tokens = time_passed * self.tokens_per_second
            current_tokens = min(tokens_in_bucket + new_tokens, self.max_tokens)

            # Check if we have enough tokens
            if current_tokens < tokens:
                # Not enough tokens, update bucket with new tokens
                self.buckets[key] = (current_tokens, now)
                return False

            # Consume tokens and update bucket
            self.buckets[key] = (current_tokens - tokens, now)
            return True

# Create token bucket rate limiter
token_bucket = TokenBucket(
    tokens_per_second=5.0,  # 5 tokens per second (300 per minute)
    max_tokens=10.0         # Max burst of 10 requests
)

# Rate limit dependency
async def rate_limit(request: Request, tokens: float = 1.0):
    client_ip = request.client.host
    if not await token_bucket.consume(client_ip, tokens):
        retry_after = max(1, tokens / token_bucket.tokens_per_second)
        raise HTTPException(
            status_code=429,
            detail="Rate limit exceeded",
            headers={"Retry-After": str(int(retry_after))}
        )

# Apply rate limiting to endpoints
@app.get("/light/", dependencies=[Depends(lambda: rate_limit(tokens=1.0))])
async def light_endpoint():
    return {"message": "Light endpoint (costs 1 token)"}

@app.get("/medium/", dependencies=[Depends(lambda: rate_limit(tokens=2.0))])
async def medium_endpoint():
    return {"message": "Medium endpoint (costs 2 tokens)"}

@app.get("/heavy/", dependencies=[Depends(lambda: rate_limit(tokens=5.0))])
async def heavy_endpoint():
    return {"message": "Heavy endpoint (costs 5 tokens)"}

```

## Using Redis for Distributed Rate Limiting

For production applications, especially in a multi-server environment, use Redis to store rate limiting data:

```python
from fastapi import FastAPI, Request, Depends, HTTPException
import aioredis
import time
from typing import Optional

app = FastAPI()

# Initialize Redis connection
async def get_redis():
    # Create a Redis connection
    redis = await aioredis.create_redis_pool("redis://localhost")
    try:
        yield redis
    finally:
        # Close Redis connection
        redis.close()
        await redis.wait_closed()

# Redis-based rate limiter
async def redis_rate_limit(
    request: Request,
    redis: aioredis.Redis = Depends(get_redis),
    limit: int = 60,
    window: int = 60,
    key_prefix: str = "ratelimit"
):
    # Get client identifier (IP address in this case)
    client_id = request.client.host

    # Create a unique key for this client
    key = f"{key_prefix}:{client_id}"

    # Get the current timestamp
    current_timestamp = int(time.time())

    # Clean up old request records and count requests in the current window
    # This Lua script atomically:
    # 1. Removes timestamps older than the window
    # 2. Adds the current timestamp
    # 3. Returns the count of timestamps in the window
    script = """
    local key = KEYS[1]
    local window = tonumber(ARGV[1])
    local current_timestamp = tonumber(ARGV[2])

    -- Remove timestamps older than the window
    redis.call('ZREMRANGEBYSCORE', key, 0, current_timestamp - window)

    -- Add current timestamp
    redis.call('ZADD', key, current_timestamp, current_timestamp .. '-' .. math.random())

    -- Get count of timestamps in window
    local count = redis.call('ZCARD', key)

    -- Set key expiration to ensure cleanup
    redis.call('EXPIRE', key, window)

    return count
    """

    # Execute the script
    count = await redis.eval(
        script,
        keys=[key],
        args=[window, current_timestamp]
    )

    # Check if rate limit exceeded
    if count > limit:
        # Calculate when client can retry
        retry_after = window

        raise HTTPException(
            status_code=429,
            detail="Rate limit exceeded",
            headers={
                "Retry-After": str(retry_after),
                "X-RateLimit-Limit": str(limit),
                "X-RateLimit-Remaining": "0",
                "X-RateLimit-Reset": str(int(time.time()) + window)
            }
        )

    # Return rate limit headers
    request.state.rate_limit_headers = {
        "X-RateLimit-Limit": str(limit),
        "X-RateLimit-Remaining": str(limit - count),
        "X-RateLimit-Reset": str(int(time.time()) + window)
    }

# Middleware to add rate limit headers to responses
@app.middleware("http")
async def add_rate_limit_headers(request: Request, call_next):
    response = await call_next(request)

    # Add rate limit headers if available
    if hasattr(request.state, "rate_limit_headers"):
        for key, value in request.state.rate_limit_headers.items():
            response.headers[key] = value

    return response

# Apply rate limiting to endpoints
@app.get("/api/public/", dependencies=[Depends(redis_rate_limit)])
async def public_api():
    return {"message": "Public API with standard rate limiting"}

@app.get(
    "/api/premium/",
    dependencies=[
        Depends(
            lambda request, redis: redis_rate_limit(
                request, redis, limit=200, window=60, key_prefix="premium"
            )
        )
    ]
)
async def premium_api():
    return {"message": "Premium API with higher rate limits"}

```

### Whitelist and Blacklist for IP-based Rate Limiting

```python
from fastapi import FastAPI, Request, Depends, HTTPException
from ipaddress import IPv4Address, IPv4Network
from typing import List, Set, Optional

app = FastAPI()

# Configuration for IP-based access control
WHITELIST_IPS: Set[str] = {"127.0.0.1", "192.168.1.1"}
WHITELIST_NETWORKS: List[IPv4Network] = [IPv4Network("10.0.0.0/8")]
BLACKLIST_IPS: Set[str] = {"123.456.789.0"}

def is_ip_allowed(client_ip: str) -> bool:
    # Check if IP is in blacklist
    if client_ip in BLACKLIST_IPS:
        return False

    # Check if IP is in whitelist
    if client_ip in WHITELIST_IPS:
        return True

    # Check if IP is in whitelisted networks
    try:
        ip_address = IPv4Address(client_ip)
        for network in WHITELIST_NETWORKS:
            if ip_address in network:
                return True
    except:
        pass

    # If not in whitelist or blacklist, allow by default
    return True

# IP access control middleware
@app.middleware("http")
async def ip_filtering_middleware(request: Request, call_next):
    client_ip = request.client.host

    if not is_ip_allowed(client_ip):
        raise HTTPException(
            status_code=403,
            detail="Access denied by IP filter"
        )

    return await call_next(request)

```

## User-based Rate Limiting

User-based rate limiting applies limits to authenticated users based on their identity.

### Implementing User-based Rate Limiting

```python
from fastapi import FastAPI, Depends, HTTPException, Request
from fastapi.security import OAuth2PasswordBearer
import time
from collections import defaultdict
import asyncio
from typing import Dict, Optional

app = FastAPI()

# OAuth2 token handling
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

# Mock function to get user from token
async def get_current_user(token: str = Depends(oauth2_scheme)):
    # In a real application, validate token and fetch user
    # This is a mock implementation
    return {"id": token, "tier": "premium" if token.startswith("p") else "standard"}

# Rate limiter for user tiers
class UserTierRateLimiter:
    def __init__(self):
        # Define limits per tier
        self.tier_limits = {
            "standard": {"rate": 60, "window": 60},  # 60 requests per minute
            "premium": {"rate": 180, "window": 60},  # 180 requests per minute
            "admin": {"rate": 600, "window": 60}     # 600 requests per minute
        }

        # Store request timestamps per user
        self.user_requests = defaultdict(list)
        self.lock = asyncio.Lock()

    async def check_rate_limit(
        self,
        user_id: str,
        tier: str
    ) -> Dict[str, int]:
        # Get limits for this tier
        tier_config = self.tier_limits.get(tier, self.tier_limits["standard"])
        rate = tier_config["rate"]
        window = tier_config["window"]

        async with self.lock:
            # Get current timestamp
            now = time.time()

            # Get user's request history
            user_history = self.user_requests[user_id]

            # Remove timestamps outside the window
            self.user_requests[user_id] = [
                ts for ts in user_history if ts > now - window
            ]

            # Check if rate limit is exceeded
            current_count = len(self.user_requests[user_id])
            if current_count >= rate:
                # Rate limit exceeded
                return {
                    "allowed": False,
                    "limit": rate,
                    "remaining": 0,
                    "reset": int(now + window - (now % window))
                }

            # Add current request
            self.user_requests[user_id].append(now)

            # Return rate limit info
            return {
                "allowed": True,
                "limit": rate,
                "remaining": rate - current_count - 1,
                "reset": int(now + window - (now % window))
            }

# Initialize rate limiter
user_rate_limiter = UserTierRateLimiter()

# Rate limit dependency for authenticated users
async def user_rate_limit(
    request: Request,
    user: dict = Depends(get_current_user)
):
    # Check rate limit for user
    result = await user_rate_limiter.check_rate_limit(
        user_id=user["id"],
        tier=user["tier"]
    )

    # If rate limit exceeded, raise exception
    if not result["allowed"]:
        raise HTTPException(
            status_code=429,
            detail="Rate limit exceeded for your user tier",
            headers={
                "Retry-After": str(result["reset"] - int(time.time())),
                "X-RateLimit-Limit": str(result["limit"]),
                "X-RateLimit-Remaining": "0",
                "X-RateLimit-Reset": str(result["reset"])
            }
        )

    # Add rate limit info to request state
    request.state.rate_limit_headers = {
        "X-RateLimit-Limit": str(result["limit"]),
        "X-RateLimit-Remaining": str(result["remaining"]),
        "X-RateLimit-Reset": str(result["reset"])
    }

# Add middleware to include rate limit headers
@app.middleware("http")
async def add_rate_limit_headers(request: Request, call_next):
    response = await call_next(request)

    if hasattr(request.state, "rate_limit_headers"):
        for key, value in request.state.rate_limit_headers.items():
            response.headers[key] = value

    return response

# Protected endpoint with rate limiting
@app.get("/api/user/profile", dependencies=[Depends(user_rate_limit)])
async def user_profile(user: dict = Depends(get_current_user)):
    return {
        "user_id": user["id"],
        "tier": user["tier"],
        "message": f"Welcome to your {user['tier']} profile!"
    }

```

## Handling Rate Limit Exceeded Scenarios

When a client exceeds the rate limit, there are several ways to handle it:

### 1. Return 429 Too Many Requests

```python
from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse

app = FastAPI()

@app.exception_handler(HTTPException)
async def rate_limit_exception_handler(request: Request, exc: HTTPException):
    if exc.status_code == 429:
        return JSONResponse(
            status_code=429,
            content={
                "error": "Rate limit exceeded",
                "detail": exc.detail,
                "type": "rate_limit_error"
            },
            headers=exc.headers
        )

    # For other HTTP exceptions, re-raise
    raise exc

```

### 2. Queue Requests for Later Processing

```python
from fastapi import FastAPI, Request, BackgroundTasks
import asyncio
import time
from typing import Dict, Deque, Tuple
from collections import deque

app = FastAPI()

# Queue for delayed processing
request_queue: Dict[str, Deque[Tuple[float, dict]]] = {}
queue_lock = asyncio.Lock()

# Process queued requests in the background
async def process_queued_requests():
    while True:
        now = time.time()

        async with queue_lock:
            # Process each client's queue
            for client_ip, queue in list(request_queue.items()):
                while queue and queue[0][0] <= now:
                    # Get request data
                    _, request_data = queue.popleft()

                    # Process request
                    try:
                        # Here you would actually process the request
                        print(f"Processing queued request: {request_data}")
                    except Exception as e:
                        print(f"Error processing queued request: {e}")

                # Remove empty queues
                if not queue:
                    del request_queue[client_ip]

        # Sleep before checking again
        await asyncio.sleep(0.1)

# Start background task on startup
@app.on_event("startup")
async def startup_event():
    asyncio.create_task(process_queued_requests())

# Endpoint that queues requests when rate limited
@app.post("/api/queue-if-limited")
async def queue_if_limited(
    request: Request,
    data: dict,
    background_tasks: BackgroundTasks
):
    client_ip = request.client.host

    # Check if client is rate limited (simplified)
    is_rate_limited = client_ip.startswith("192.")  # Example check

    if is_rate_limited:
        # Queue the request for later processing
        delay = 5.0  # 5 seconds delay

        async with queue_lock:
            if client_ip not in request_queue:
                request_queue[client_ip] = deque()

            # Add to queue with execution time
            request_queue[client_ip].append(
                (time.time() + delay, data)
            )

        return {
            "status": "queued",
            "message": "Request has been queued for processing",
            "estimated_wait": delay
        }

    # Process immediately if not rate limited
    return {
        "status": "processed",
        "message": "Request processed immediately",
        "data": data
    }

```

```python
# Rate limit check function (simplified)
```

### 4. Provide Alternative Resources or Cached Data

```python
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
import time
from typing import Dict

app = FastAPI()

# Simple cache
data_cache: Dict[str, dict] = {}
cache_timestamps: Dict[str, float] = {}

@app.get("/api/fresh-data")
async def get_fresh_data(request: Request):
    client_ip = request.client.host
    endpoint = request.url.path
    cache_key = f"{client_ip}:{endpoint}"

    # Check if rate limited (simplified)
    is_rate_limited = client_ip.startswith("192.")

    if is_rate_limited:
        # Check if we have cached data
        if cache_key in data_cache:
            cached_data = data_cache[cache_key]
            cache_time = cache_timestamps[cache_key]
            age = time.time() - cache_time

            # Return cached data with headers indicating cache
            return JSONResponse(
                content={
                    "data": cached_data,
                    "cached": True,
                    "cache_age_seconds": int(age)
                },
                headers={
                    "X-Rate-Limited": "true",
                    "X-Cache-Age": str(int(age)),
                    "Retry-After": "60"
                }
            )

        # No cached data available
        return JSONResponse(
            status_code=429,
            content={
                "error": "Rate limit exceeded and no cached data available",
                "retry_after": 60
            },
            headers={"Retry-After": "60"}
        )

    # Generate fresh data
    fresh_data = {"timestamp": time.time(), "value": "fresh data"}

    # Cache the data for this client
    data_cache[cache_key] = fresh_data
    cache_timestamps[cache_key] = time.time()

    return {"data": fresh_data, "cached": False}

```

### Dynamic Rate Limiting Based on Server Load

Adjust rate limits dynamically based on server load to prevent system overload:

```python
from fastapi import FastAPI, Request, HTTPException, Depends
import psutil
import time
import asyncio
from typing import Dict, Tuple

app = FastAPI()

# Configure dynamic rate limiting
class DynamicRateLimiter:
    def __init__(
        self,
        base_rate: int = 100,
        base_window: int = 60,
        max_cpu_percent: float = 70.0,
        check_interval: int = 5
    ):
        self.base_rate = base_rate
        self.base_window = base_window
        self.max_cpu_percent = max_cpu_percent
        self.check_interval = check_interval

        # Current rate limit settings
        self.current_rate = base_rate
        self.current_window = base_window

        # Last time we checked system load
        self.last_check = 0

        # Client request counters
        self.client_requests: Dict[str, Dict[str, any]] = {}
        self.lock = asyncio.Lock()

    async def update_limits_based_on_load(self):
        # Only check periodically to reduce overhead
        current_time = time.time()
        if current_time - self.last_check < self.check_interval:
            return

        # Update last check time
        self.last_check = current_time

        # Get current CPU usage
        cpu_percent = psutil.cpu_percent(interval=0.1)

        # Adjust rate based on CPU load
        if cpu_percent > self.max_cpu_percent:
            # System is under high load, reduce rate limit
            reduction_factor = (cpu_percent / self.max_cpu_percent)
            self.current_rate = max(10, int(self.base_rate / reduction_factor))
        else:
            # System load is acceptable, gradually restore base rate
            if self.current_rate < self.base_rate:
                self.current_rate = min(
                    self.base_rate,
                    int(self.current_rate * 1.1)  # Increase by 10%
                )
            else:
                self.current_rate = self.base_rate

        print(f"CPU: {cpu_percent}%, Rate limit adjusted to: {self.current_rate} req/min")

    async def check_rate_limit(self, client_id: str) -> Tuple[bool, Dict[str, any]]:
        # Update limits based on system load
        await self.update_limits_based_on_load()

        async with self.lock:
            current_time = time.time()
            window_start = current_time - self.current_window

            # Initialize client data if not exists
            if client_id not in self.client_requests:
                self.client_requests[client_id] = {
                    "requests": [],
                    "blocked_until": 0
                }

            client_data = self.client_requests[client_id]

            # Check if client is temporarily blocked
            if client_data["blocked_until"] > current_time:
                return False, {
                    "retry_after": int(client_data["blocked_until"] - current_time)
                }

            # Clean up old requests
            client_data["requests"] = [
                ts for ts in client_data["requests"] if ts > window_start
            ]

            # Check if rate limit exceeded
            if len(client_data["requests"]) >= self.current_rate:
                # Block client for a short time to reduce load
                client_data["blocked_until"] = current_time + 5  # Block for 5 seconds

                return False, {
                    "retry_after": 5,
                    "limit": self.current_rate,
                    "reset": int(window_start + self.current_window)
                }

            # Record this request
            client_data["requests"].append(current_time)

            return True, {
                "limit": self.current_rate,
                "remaining": self.current_rate - len(client_data["requests"]),
                "reset": int(window_start + self.current_window)
            }

# Initialize dynamic rate limiter
dynamic_limiter = DynamicRateLimiter(
    base_rate=100,          # 100 requests per minute by default
    max_cpu_percent=70.0,   # Start reducing when CPU > 70%
    check_interval=5        # Check system load every 5 seconds
)

# Rate limit dependency
```

### Weighted Token Bucket for Complex API Costing

Implement a more sophisticated token bucket that applies different weights to different operations:

```python
from fastapi import FastAPI, Request, Depends, HTTPException
import time
import asyncio
from enum import Enum
from typing import Dict, Optional

app = FastAPI()

# Define API operation costs
class OperationCost(float, Enum):
    READ = 1.0
    LIST = 2.0
    SEARCH = 5.0
    CREATE = 3.0
    UPDATE = 3.0
    DELETE = 5.0
    BULK_OPERATION = 10.0
    EXPORT = 20.0

# Advanced token bucket with operation weights
class WeightedTokenBucket:
    def __init__(
        self,
        refill_rate: float = 10.0,    # Tokens per second
        max_tokens: float = 60.0,     # Bucket capacity
        max_debt: float = -30.0       # Maximum negative balance allowed
    ):
        self.refill_rate = refill_rate
        self.max_tokens = max_tokens
        self.max_debt = max_debt
        self.buckets: Dict[str, Dict[str, float]] = {}
        self.lock = asyncio.Lock()

    async def consume(
        self,
        key: str,
        cost: float,
        allow_negative: bool = True
    ) -> Dict[str, any]:
        async with self.lock:
            now = time.time()

            # Initialize bucket if needed
            if key not in self.buckets:
                self.buckets[key] = {
                    "tokens": self.max_tokens,
                    "last_refill": now
                }

            bucket = self.buckets[key]

            # Calculate time passed and refill tokens
            time_passed = now - bucket["last_refill"]
            new_tokens = time_passed * self.refill_rate

            # Update bucket tokens (capped at max_tokens)
            bucket["tokens"] = min(bucket["tokens"] + new_tokens, self.max_tokens)
            bucket["last_refill"] = now

            # Check if we can consume tokens
            if bucket["tokens"] < cost and (not allow_negative or bucket["tokens"] - cost < self.max_debt):
                # Cannot consume - calculate wait time
                if allow_negative:
                    missing_tokens = cost - bucket["tokens"] + self.max_debt
                else:
                    missing_tokens = cost - bucket["tokens"]

                wait_time = missing_tokens / self.refill_rate

                return {
                    "allowed": False,
                    "wait_time": wait_time,
                    "tokens": bucket["tokens"],
                    "cost": cost
                }

            # Consume tokens
            bucket["tokens"] -= cost

            return {
                "allowed": True,
                "tokens": bucket["tokens"],
                "cost": cost
            }

# Initialize weighted token bucket

    max_debt=-30.0      # Allow going negative to -30 tokens
)

            detail=f"Rate limit exceeded. Operation cost: {operation.value} tokens",
            headers={
                "Retry-After": str(retry_after),
                "X-Cost": str(operation.value),
                "X-Tokens-Remaining": str(result["tokens"])
            }
        )

    # Store tokens info for headers
    request.state.tokens_info = {
        "tokens_remaining": result["tokens"],
        "operation_cost": operation.value
    }
```

### Implementing a Leaky Bucket Algorithm

The Leaky Bucket algorithm is another common rate limiting strategy that processes requests at a constant rate:

```python
from fastapi import FastAPI, Request, HTTPException, Depends
import time
import asyncio
from typing import Dict, List, Tuple

app = FastAPI()

# Leaky Bucket implementation
class LeakyBucket:
    def __init__(
        self,
        capacity: int = 60,     # Maximum queue size
        leak_rate: float = 1.0  # Requests processed per second
    ):
        self.capacity = capacity
        self.leak_rate = leak_rate  # How many requests leak out per second
        self.buckets: Dict[str, Dict[str, any]] = {}
        self.lock = asyncio.Lock()

    async def add_request(self, key: str) -> Tuple[bool, Dict[str, any]]:
        async with self.lock:
            now = time.time()

            # Initialize bucket if needed
            if key not in self.buckets:
                self.buckets[key] = {
                    "queue": [],           # Request timestamps in queue
                    "last_leak": now,      # Last time we leaked a request
                    "processing_rate": 1.0 / self.leak_rate  # Seconds per request
                }

            bucket = self.buckets[key]

            # Calculate how many requests have leaked since last check
            time_passed = now - bucket["last_leak"]
            leaked_count = int(time_passed / bucket["processing_rate"])

            if leaked_count > 0:
                # Remove leaked requests from queue
                if leaked_count >= len(bucket["queue"]):
                    # All requests processed
                    bucket["queue"] = []
                    bucket["last_leak"] = now
                else:
                    # Some requests processed
                    bucket["queue"] = bucket["queue"][leaked_count:]
                    bucket["last_leak"] = bucket["last_leak"] + (leaked_count * bucket["processing_rate"])

            # Check if bucket is full
            if len(bucket["queue"]) >= self.capacity:
                # Calculate wait time for this request
                queue_position = len(bucket["queue"]) - self.capacity + 1
                wait_time = queue_position * bucket["processing_rate"]

                return False, {
                    "queue_size": len(bucket["queue"]),
                    "capacity": self.capacity,
                    "wait_time": wait_time
                }

            # Add request to queue
            bucket["queue"].append(now)

            # If this is the only request, update last_leak
            if len(bucket["queue"]) == 1:
                bucket["last_leak"] = now

            return True, {
                "queue_size": len(bucket["queue"]),
                "capacity": self.capacity,
                "processing_rate": bucket["processing_rate"]
            }

# Initialize leaky bucket
leaky_bucket = LeakyBucket(
    capacity=10,     # Maximum 10 requests in queue
    leak_rate=1.0    # Process 1 request per second
)

# Rate limit dependency with leaky bucket
async def leaky_bucket_limit(request: Request):
    client_id = request.client.host

    # Try to add request to bucket
    allowed, info = await leaky_bucket.add_request(client_id)

    if not allowed:
        # Rate limited - queue is full
        retry_after = int(info["wait_time"]) + 1

        raise HTTPException(
            status_code=429,
            detail="Too many requests. Server is processing your previous requests.",
            headers={
                "Retry-After": str(retry_after),
                "X-Queue-Size": str(info["queue_size"]),
                "X-Queue-Capacity": str(info["capacity"])
            }
        )

    # Store queue info for headers
    request.state.queue_info = info

# Add headers via middleware
@app.middleware("http")
async def add_queue_info_headers(request: Request, call_next):
    response = await call_next(request)

    if hasattr(request.state, "queue_info"):
        info = request.state.queue_info
        response.headers["X-Queue-Size"] = str(info["queue_size"])
        response.headers["X-Queue-Capacity"] = str(info["capacity"])
        response.headers["X-Processing-Rate"] = str(round(info["processing_rate"], 2))

    return response
```

## Rate Limiting with Concurrency Control

Limit not just the rate of requests but also the number of concurrent requests being processed:

```python
from fastapi import FastAPI, Request, Depends, HTTPException
import asyncio
from typing import Dict, Set, Optional

app = FastAPI()

# Concurrency limiter
class ConcurrencyLimiter:
    def __init__(
        self,
        max_concurrent: int = 10  # Maximum concurrent requests
    ):
        self.max_concurrent = max_concurrent
        self.current_processing: Dict[str, Set[str]] = {}
        self.lock = asyncio.Lock()

    async def acquire(self, client_id: str, request_id: str = None) -> bool:
        """Try to acquire a slot for processing"""
        if request_id is None:
            request_id = str(id(asyncio.current_task()))

        async with self.lock:
            # Initialize set for client if needed
            if client_id not in self.current_processing:
                self.current_processing[client_id] = set()

            # Check if client has reached limit
            if len(self.current_processing[client_id]) >= self.max_concurrent:
                return False

            # Add request ID to processing set
            self.current_processing[client_id].add(request_id)
            return True

    async def release(self, client_id: str, request_id: str = None) -> None:
        """Release a processing slot"""
        if request_id is None:
            request_id = str(id(asyncio.current_task()))

        async with self.lock:
            if client_id in self.current_processing:
                self.current_processing[client_id].discard(request_id)

    def get_active_count(self, client_id: str) -> int:
        """Get count of active requests for client"""
        return len(self.current_processing.get(client_id, set()))

# Initialize concurrency limiter
concurrency_limiter = ConcurrencyLimiter(max_concurrent=3)

# Concurrency limit dependency
async def limit_concurrency(request: Request):
    client_id = request.client.host
    request_id = str(id(asyncio.current_task()))

    # Try to acquire processing slot
    if not await concurrency_limiter.acquire(client_id, request_id):
        active_count = concurrency_limiter.get_active_count(client_id)

        raise HTTPException(
            status_code=429,
            detail=f"Maximum concurrent requests reached ({active_count}/{concurrency_limiter.max_concurrent})",
            headers={
                "Retry-After": "5",
                "X-Concurrent-Requests": str(active_count),
                "X-Max-Concurrent": str(concurrency_limiter.max_concurrent)
            }
        )

    try:
        # Store concurrency info
        request.state.concurrency_info = {
            "active": concurrency_limiter.get_active_count(client_id),
            "max": concurrency_limiter.max_concurrent
        }

        # Continue processing
        yield
    finally:
        # Release the slot when done
        await concurrency_limiter.release(client_id, request_id)

# Add headers via middleware
@app.middleware("http")
async def add_concurrency_headers(request: Request, call_next):
    response = await call_next(request)

    if hasattr(request.state, "concurrency_info"):
        info = request.state.concurrency_info
        response.headers["X-Concurrent-Requests"] = str(info["active"])
        response.headers["X-Max-Concurrent"] = str(info["max"])

    return response

# Apply concurrency limiting to a long-running endpoint
@app.get("/api/long-process", dependencies=[Depends(limit_concurrency)])
async def long_running_process():
    # Simulate a long-running process
    await asyncio.sleep(5)
    return {
        "message": "Long-running process completed"
    }
```

## Rate Limiting for WebSockets

Rate limiting WebSocket connections and messages:

```python
from fastapi import FastAPI, WebSocket, WebSocketDisconnect, HTTPException
import asyncio
import time
from typing import Dict, List, Set

app = FastAPI()

# WebSocket rate limiter
class WebSocketRateLimiter:
    def __init__(
        self,
        max_connections_per_client: int = 3,
        max_messages_per_minute: int = 60
    ):
        self.max_connections = max_connections_per_client
        self.max_messages = max_messages_per_minute
        self.client_connections: Dict[str, Set[WebSocket]] = {}
        self.message_counters: Dict[str, List[float]] = {}
        self.lock = asyncio.Lock()

    async def check_connection_limit(self, client_id: str, websocket: WebSocket) -> bool:
        """Check if client has reached connection limit"""
        async with self.lock:
            if client_id not in self.client_connections:
                self.client_connections[client_id] = set()

            # Check if client has reached connection limit
            if len(self.client_connections[client_id]) >= self.max_connections:
                return False

            # Add connection to client's set
            self.client_connections[client_id].add(websocket)
            return True

    async def remove_connection(self, client_id: str, websocket: WebSocket) -> None:
        """Remove connection when client disconnects"""
        async with self.lock:
            if client_id in self.client_connections:
                self.client_connections[client_id].discard(websocket)

    async def check_message_rate_limit(self, client_id: str) -> bool:
        """Check if client has exceeded message rate limit"""
        async with self.lock:
            now = time.time()
            window_start = now - 60  # 1 minute window

            if client_id not in self.message_counters:
                self.message_counters[client_id] = []

            # Clean up old message timestamps
            self.message_counters[client_id] = [
                timestamp for timestamp in self.message_counters[client_id]
                if timestamp > window_start
            ]

            # Check if client has reached message limit
            if len(self.message_counters[client_id]) >= self.max_messages:
                return False

            # Record this message
            self.message_counters[client_id].append(now)
            return True

    max_connections_per_client=3,
    max_messages_per_minute=60
)

    # Get client ID (IP address)

        # Too many connections for this client
        await websocket.send_json({
            "error": "Too many concurrent connections",
            "max_connections": ws_limiter.max_connections
        })
        await websocket.close(code=1008)  # Policy violation
        return

    try:
        # Process messages
        while True:
            # Receive message
            message = await websocket.receive_text()

            # Check message rate limit
            if not await ws_limiter.check_message_rate_limit(client_id):
                # Too many messages
                await websocket.send_json({
                    "error": "Message rate limit exceeded",
                    "max_messages": ws_limiter.max_messages,
                    "window": "60 seconds"
                })
                continue  # Don't disconnect, just don't process this message

            # Process message normally
            await websocket.send_text(f"You sent: {message}")
    except WebSocketDisconnect:
        # Clean up when client disconnects
        await ws_limiter.remove_connection(client_id, websocket)
```

## Adaptive Rate Limiting

Implement adaptive rate limiting that adjusts based on client behavior:

```python
from fastapi import FastAPI, Request, HTTPException, Depends
import time
import asyncio
import statistics
from typing import Dict, List, Optional, Tuple

app = FastAPI()

# Adaptive rate limiter
class AdaptiveRateLimiter:
    def __init__(
        self,
        base_rate: int = 60,       # Base rate (requests per minute)
        min_rate: int = 10,        # Minimum rate
        max_rate: int = 200,       # Maximum rate
        suspicious_threshold: float = 0.8,  # Threshold for suspicious activity (0-1)
        adaptation_period: int = 10  # Minutes between rate adjustments
    ):
        self.base_rate = base_rate
        self.min_rate = min_rate
        self.max_rate = max_rate
        self.suspicious_threshold = suspicious_threshold
        self.adaptation_period = adaptation_period * 60  # Convert to seconds

        # Per-client data
        self.client_rates: Dict[str, int] = {}
        self.request_history: Dict[str, List[float]] = {}
        self.last_adaptation: Dict[str, float] = {}
        self.lock = asyncio.Lock()

    async def analyze_client_behavior(self, client_id: str) -> Dict[str, any]:
        """Analyze client behavior patterns"""
        if client_id not in self.request_history:
            return {"pattern": "new", "risk_score": 0.5}

        history = self.request_history[client_id]
        if len(history) < 10:
            return {"pattern": "limited-history", "risk_score": 0.3}

        # Calculate inter-request intervals
        intervals = []
        for i in range(1, len(history)):
            intervals.append(history[i] - history[i-1])

        # Look for suspicious patterns
        risk_score = 0.0

        # 1. Check for extremely uniform requests (bot-like)
        if len(intervals) > 5:
            stdev = statistics.stdev(intervals) if len(intervals) > 1 else 0
            mean = statistics.mean(intervals)
            variation_coeff = stdev / mean if mean > 0 else 0

            if variation_coeff < 0.1:  # Very uniform timing
                risk_score += 0.4

        # 2. Check for rapid bursts
        min_interval = min(intervals) if intervals else 1.0
        if min_interval < 0.05:  # Less than 50ms between requests
            risk_score += 0.3

        # 3. Check request volume
        recent_window = 60  # Last minute
        now = time.time()
        recent_count = sum(1 for ts in history if ts > now - recent_window)

        current_rate = self.client_rates.get(client_id, self.base_rate)
        if recent_count > current_rate * 0.9:  # Using >90% of allowed rate
            risk_score += 0.2

        # Classify pattern
        pattern = "normal"
        if risk_score > 0.7:
            pattern = "high-risk"
        elif risk_score > 0.4:
            pattern = "suspicious"

        return {
            "pattern": pattern,
            "risk_score": risk_score,
            "request_count": len(history),
            "recent_count": recent_count
        }

    async def adapt_rate_limit(self, client_id: str) -> None:
        """Adapt rate limit based on client behavior"""
        now = time.time()

        # Only adapt periodically
        if client_id in self.last_adaptation:
            time_since_last = now - self.last_adaptation[client_id]
            if time_since_last < self.adaptation_period:
                return

        # Analyze client behavior
        analysis = await self.analyze_client_behavior(client_id)

        # Get current rate
        current_rate = self.client_rates.get(client_id, self.base_rate)

        # Adjust rate based on behavior
        if analysis["pattern"] == "high-risk":
            # Significantly reduce rate for high-risk clients
            new_rate = max(self.min_rate, int(current_rate * 0.5))
        elif analysis["pattern"] == "suspicious":
            # Moderately reduce rate for suspicious clients
            new_rate = max(self.min_rate, int(current_rate * 0.8))
        elif analysis["pattern"] == "normal" and analysis["risk_score"] < 0.2:
            # Reward good behavior with higher limits
            new_rate = min(self.max_rate, int(current_rate * 1.1))
        else:
            # Keep current rate
            new_rate = current_rate

        # Update client rate
        self.client_rates[client_id] = new_rate
        self.last_adaptation[client_id] = now

        print(f"Adapted rate for {client_id}: {current_rate} -> {new_rate} (pattern: {analysis['pattern']})")

    async def check_rate_limit(self, client_id: str) -> Tuple[bool, Dict[str, any]]:
    """Check if client has exceeded their adaptive rate limit"""
    async with self.lock:
        now = time.time()
        window_start = now - 60  # 1-minute rolling window

        # Initialize client data if needed
        if client_id not in self.request_history:
            self.request_history[client_id] = []
            self.client_rates[client_id] = self.base_rate

        # Clean up old request timestamps
        self.request_history[client_id] = [
            ts for ts in self.request_history[client_id]
            if ts > now - 3600  # Keep last hour for analysis
        ]

        # Adapt rate limit if needed
        await self.adapt_rate_limit(client_id)

        # Get client's current rate limit
        current_rate = self.client_rates[client_id]

        # Count requests in the current window
        window_count = sum(1 for ts in self.request_history[client_id] if ts > window_start)

        # Check if rate limit exceeded
        if window_count >= current_rate:
            return False, {
                "limit": current_rate,
                "count": window_count,
                "retry_after": 60 - (now - window_start)
            }

        # Record this request
        self.request_history[client_id].append(now)

        return True, {
            "limit": current_rate,
            "count": window_count + 1,
            "remaining": current_rate - window_count - 1
        }
```

## Using Circuit Breakers with Rate Limiting

Combine rate limiting with circuit breakers to provide additional protection against system overload:

```python
from fastapi import FastAPI, Request, HTTPException, Depends

# Circuit breaker states
class CircuitState(str, Enum):
    CLOSED = "closed"      # Normal operation
    OPEN = "open"          # Circuit is tripped, requests fail fast
    HALF_OPEN = "half_open"  # Testing if system has recovered

# Circuit breaker implementation
class CircuitBreaker:
    def __init__(
        self,
        failure_threshold: int = 5,
        recovery_timeout: int = 30,
        half_open_max: int = 3
    ):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.half_open_max = half_open_max

        self.state = CircuitState.CLOSED
        self.failures = 0
        self.last_failure_time = 0
        self.half_open_count = 0
        self.lock = asyncio.Lock()

    async def __call__(
        self,
        func: Callable,
        *args: Any,
        **kwargs: Any
    ) -> Any:
        async with self.lock:
            # Check circuit state
            now = time.time()

            if self.state == CircuitState.OPEN:
                # Check if recovery timeout has elapsed
                if now - self.last_failure_time > self.recovery_timeout:
                    # Try half-open state
                    self.state = CircuitState.HALF_OPEN
                    self.half_open_count = 0
                else:
                    # Circuit is open, fail fast
                    raise HTTPException(
                        status_code=503,
                        detail="Service temporarily unavailable (circuit open)",
                        headers={"Retry-After": str(int(self.recovery_timeout - (now - self.last_failure_time)))}
                    )

            if self.state == CircuitState.HALF_OPEN:
                # Only allow limited number of requests in half-open state
                if self.half_open_count >= self.half_open_max:
                    raise HTTPException(
                        status_code=503,
                        detail="Service temporarily unavailable (circuit half-open)",
                        headers={"Retry-After": "5"}
                    )
                self.half_open_count += 1

        try:
            # Execute the function
            result = await func(*args, **kwargs)

            # On success
            async with self.lock:
                if self.state == CircuitState.HALF_OPEN:
                    # Request succeeded in half-open state, close circuit
                    self.state = CircuitState.CLOSED
                    self.failures = 0
                elif self.state == CircuitState.CLOSED and self.failures > 0:
                    # Request succeeded in closed state, reduce failure count
                    self.failures -= 1

            return result

        except Exception as e:
            # On failure
            async with self.lock:
                self.failures += 1
                self.last_failure_time = time.time()

                if self.state == CircuitState.CLOSED and self.failures >= self.failure_threshold:
                    # Too many failures, open circuit
                    self.state = CircuitState.OPEN
                elif self.state == CircuitState.HALF_OPEN:
                    # Failure in half-open state, re-open circuit
                    self.state = CircuitState.OPEN

            # Re-raise the exception
            raise e
```

## Strategic Response Throttling

Instead of rejecting requests, strategically slow down responses when under load:

```python
from fastapi import FastAPI, Request

import asyncio
import random
import psutil
from typing import Dict, Tuple

# Response throttler
class ResponseThrottler:
    def __init__(
        self,
        cpu_threshold: float = 70.0,  # CPU percentage threshold
        max_delay: float = 2.0,       # Maximum delay in seconds
        base_delay: float = 0.1,      # Base delay for all requests
        check_interval: float = 5.0    # Interval to check system load
    ):
        self.cpu_threshold = cpu_threshold
        self.max_delay = max_delay
        self.base_delay = base_delay
        self.check_interval = check_interval

        self.last_check = 0
        self.current_cpu = 0
        self.current_delay = base_delay

    async def update_load_metrics(self):
        """Update system load metrics (periodically)"""
        now = time.time()
        if now - self.last_check < self.check_interval:
            return

        # Update CPU usage
        self.current_cpu = psutil.cpu_percent(interval=0.1)

        # Calculate appropriate delay based on CPU load
        if self.current_cpu > self.cpu_threshold:
            # Increase delay as CPU usage increases
            cpu_ratio = (self.current_cpu - self.cpu_threshold) / (100 - self.cpu_threshold)
            self.current_delay = self.base_delay + (cpu_ratio * (self.max_delay - self.base_delay))
        else:
            # Normal load, use base delay
            self.current_delay = self.base_delay

        self.last_check = now

    async def get_delay(self, client_id: str, path: str) -> float:
        """Get delay time for a specific request"""
        await self.update_load_metrics()

        # Apply jitter to prevent thundering herd problem
        jitter = random.uniform(0.8, 1.2)

        # Apply delay based on CPU load
        return self.current_delay * jitter
```

```python
        self.request_history: Dict[str, Dict[str, List[float]]] = {}

        # Lock for thread safety
        self.lock = asyncio.Lock()

        self.client_quotas[client_id] = quotas

            # Initialize client history if needed
            if client_id not in self.request_history:
                self.request_history[client_id] = {
                    "per_second": [],
                    "per_minute": [],
                    "per_hour": [],
                    "per_day": []
                }

            # Update and check each quota level
            # Per second
            history["per_second"] = [ts for ts in history["per_second"] if ts > now - 1]
            if len(history["per_second"]) >= quotas["per_second"]:
                return False, {
                    "level": "per_second",
                    "limit": quotas["per_second"],
                    "remaining": 0,
                    "reset": int(now) + 1
                }

            # Per minute
            history["per_minute"] = [ts for ts in history["per_minute"] if ts > now - 60]
            if len(history["per_minute"]) >= quotas["per_minute"]:
                return False, {
                    "level": "per_minute",
                    "limit": quotas["per_minute"],
                    "remaining": 0,
                    "reset": int(now) + (60 - (int(now) % 60))
                }

            history["per_hour"] = [ts for ts in history["per_hour"] if ts > now - 3600]
            if len(history["per_hour"]) >= quotas["per_hour"]:
                return False, {
                    "level": "per_hour",
                    "limit": quotas["per_hour"],
                    "remaining": 0,
                    "reset": int(now) + (3600 - (int(now) % 3600))

            history["per_day"] = [ts for ts in history["per_day"] if ts > now - 86400]
            if len(history["per_day"]) >= quotas["per_day"]:
                return False, {
                    "level": "per_day",
                    "limit": quotas["per_day"],
                    "remaining": 0,
                    "reset": int(now) + (86400 - (int(now) % 86400))
                }

            # All quotas checked and not exceeded
            # Record this request in all levels
            history["per_second"].append(now)
            history["per_minute"].append(now)
            history["per_hour"].append(now)
            history["per_day"].append(now)

            # Calculate remaining quotas
            remaining = {
                "per_second": quotas["per_second"] - len(history["per_second"]),
                "per_minute": quotas["per_minute"] - len(history["per_minute"]),
                "per_hour": quotas["per_hour"] - len(history["per_hour"]),
                "per_day": quotas["per_day"] - len(history["per_day"])
            }

                "quotas": quotas,
```

## Best Practices for Rate Limiting in FastAPI

### 1. Communication with Clients

Always provide clear information to clients about rate limiting:

```python
@app.exception_handler(HTTPException)
```

### 2. Rate Limit Headers

Use standard headers to communicate rate limit information:

- `X-RateLimit-Limit`: Maximum requests allowed in the current time window
- `X-RateLimit-Remaining`: Remaining requests in the current time window
- `X-RateLimit-Reset`: Time when the current window resets (Unix timestamp)
- `Retry-After`: Seconds until client should retry

### 3. Distributed Rate Limiting

For production applications, use Redis for distributed rate limiting:

```python
# Pseudocode for Redis-based rate limiter
async def redis_rate_limit(redis_client, key, limit, window):
    # Use Redis MULTI/EXEC for atomic operations
    pipeline = redis_client.pipeline()

    # Get current timestamp
    now = int(time.time())
    window_key = f"{key}:{now // window}"

    # Increment counter for this window
    pipeline.incr(window_key)

    # Set expiration if new key
    pipeline.expire(window_key, window * 2)

    # Execute commands
    count = (await pipeline.execute())[0]

    # Check if limit exceeded
    if count > limit:
        return False, count

    return True, count
```

### 4. Tiered Rate Limiting Strategy

## Conclusion: Implementing Effective Rate Limiting

### Key Principles for Rate Limiting

1. **Defense in Depth**: Combine multiple rate limiting approaches
2. **Client Communication**: Provide clear information via headers and error responses
3. **Adaptability**: Adjust limits based on system load and client behavior
4. **Fairness**: Ensure resources are shared equitably among all clients
5. **Monitoring**: Track rate limit events to identify abuse and adjust policies

### Rate Limiting Implementation Checklist

- [ ] Define clear rate limiting policies for different client types
- [ ] Implement appropriate algorithms (token bucket, leaky bucket, fixed window)

- [ ] Add standard rate limit headers to responses
- [ ] Provide helpful error messages when limits are exceeded
- [ ] Monitor and log rate limiting events
- [ ] Implement circuit breakers for critical systems
- [ ] Consider dynamic/adaptive rate limiting for optimal performance
- [ ] Test rate limiting under various load scenarios
