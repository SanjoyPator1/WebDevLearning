# 8.4 Internationalization and Localization

## Introduction to Internationalization and Localization

Internationalization (i18n) and Localization (l10n) are essential for creating applications that can be used by people around the world in their preferred languages and formats.

- **Internationalization (i18n)**: The process of designing an application so it can be adapted to various languages and regions without engineering changes.
- **Localization (l10n)**: The process of adapting an internationalized application for a specific language or region.

### Why Implement i18n and l10n in Your API?

- **Global Reach**: Serve users from different countries and language backgrounds
- **User Experience**: Provide content in users' preferred languages
- **Legal Compliance**: Some regions require localized content by law
- **Market Expansion**: Facilitate entry into new geographical markets
- **Accessibility**: Make your application more accessible to diverse users

## Multi-language Support in FastAPI

FastAPI doesn't include built-in internationalization support, but we can implement it using various approaches.

### Basic Language Detection

First, let's implement a simple mechanism to detect the user's preferred language:

```python
from fastapi import FastAPI, Header, Query, Depends
from typing import Optional

app = FastAPI()

# Supported languages
SUPPORTED_LANGUAGES = {"en", "es", "fr", "de", "ja", "zh"}
DEFAULT_LANGUAGE = "en"

def get_language(
    accept_language: Optional[str] = Header(None),
    lang: Optional[str] = Query(None)
) -> str:
    """
    Determine the language to use based on query parameter or Accept-Language header.
    Query parameter takes precedence over header.
    """
    # First check query parameter
    if lang and lang in SUPPORTED_LANGUAGES:
        return lang

    # Then check Accept-Language header
    if accept_language:
        # Parse the Accept-Language header
        # Format: "en-US,en;q=0.9,es;q=0.8,fr;q=0.7"
        for lang_item in accept_language.split(','):
            parts = lang_item.strip().split(';')
            lang_code = parts[0].split('-')[0].lower()  # Get primary language code
            if lang_code in SUPPORTED_LANGUAGES:
                return lang_code

    # Default fallback
    return DEFAULT_LANGUAGE

@app.get("/hello")
async def hello(language: str = Depends(get_language)):
    # Simple greeting based on language
    greetings = {
        "en": "Hello, World!",
        "es": "¡Hola, Mundo!",
        "fr": "Bonjour, le Monde!",
        "de": "Hallo, Welt!",
        "ja": "こんにちは、世界！",
        "zh": "你好，世界！"
    }

    return {"message": greetings[language]}

```

### Using gettext for Translations

The GNU `gettext` system is a widely used solution for managing translations:

```python
from fastapi import FastAPI, Depends, Header, Query
import gettext
import os
from typing import Optional, Callable

app = FastAPI()

# Supported languages
SUPPORTED_LANGUAGES = {"en", "es", "fr", "de", "ja", "zh"}
DEFAULT_LANGUAGE = "en"

# Setup gettext translations
LOCALEDIR = os.path.join(os.path.dirname(__file__), "locales")
translators = {}

# Initialize translators for each language
for lang in SUPPORTED_LANGUAGES:
    try:
        translator = gettext.translation('messages', localedir=LOCALEDIR, languages=[lang])
        translators[lang] = translator.gettext
    except FileNotFoundError:
        # Fallback to identity translation if language file not found
        translators[lang] = lambda text: text

def get_language(
    accept_language: Optional[str] = Header(None),
    lang: Optional[str] = Query(None)
) -> str:
    """Determine the language based on query param or Accept-Language header"""
    # First check query parameter
    if lang and lang in SUPPORTED_LANGUAGES:
        return lang

    # Then check Accept-Language header
    if accept_language:
        for lang_item in accept_language.split(','):
            parts = lang_item.strip().split(';')
            lang_code = parts[0].split('-')[0].lower()
            if lang_code in SUPPORTED_LANGUAGES:
                return lang_code

    # Default fallback
    return DEFAULT_LANGUAGE

# Dependency to get translator function for current language
def get_translator(language: str = Depends(get_language)) -> Callable:
    return translators.get(language, translators[DEFAULT_LANGUAGE])

# Use translator in endpoint
@app.get("/greeting/{name}")
async def greeting(name: str, _: Callable = Depends(get_translator)):
    # _ is the conventional name for the gettext function
    greeting_text = _("Hello, {}!")
    return {"message": greeting_text.format(name)}

# Example with plural forms
@app.get("/items")
async def count_items(count: int, _: Callable = Depends(get_translator)):
    # This is simplified - gettext actually has better plural handling with ngettext
    if count == 0:
        return {"message": _("You have no items.")}
    elif count == 1:
        return {"message": _("You have one item.")}
    else:
        return {"message": _("You have {} items.").format(count)}

```

### Creating Translation Files

Here's how you would create the necessary translation files for gettext:

1. **Extract strings from your code**:

```bash
# Create a messages.pot template file
xgettext -d messages --from-code=UTF-8 -o messages.pot *.py

```

1. **Initialize language-specific PO files**:

```bash
# For Spanish
mkdir -p locales/es/LC_MESSAGES
msginit --locale=es --input=messages.pot --output=locales/es/LC_MESSAGES/messages.po

```

1. **Translate the strings in the PO files**:

Example content of `messages.po` for Spanish:

```
msgid "Hello, {}!"
msgstr "¡Hola, {}!"

msgid "You have no items."
msgstr "No tienes artículos."

msgid "You have one item."
msgstr "Tienes un artículo."

msgid "You have {} items."
msgstr "Tienes {} artículos."

```

1. **Compile PO files to MO format**:

```bash
msgfmt locales/es/LC_MESSAGES/messages.po -o locales/es/LC_MESSAGES/messages.mo

```

## Using a Translation Service

For more complex applications, you might want to use a dedicated translation service:

```python
from fastapi import FastAPI, Depends, Header, Query
import aiohttp
import json
import os
from typing import Optional, Dict

app = FastAPI()

# Supported languages
SUPPORTED_LANGUAGES = {"en", "es", "fr", "de", "ja", "zh"}
DEFAULT_LANGUAGE = "en"

# Translation service configuration
TRANSLATION_API_KEY = os.getenv("TRANSLATION_API_KEY")
TRANSLATION_API_URL = "https://api.translation-service.example.com/translate"

# In-memory cache for translations
translation_cache: Dict[str, Dict[str, str]] = {}

async def translate_text(text: str, source_lang: str, target_lang: str) -> str:
    """Translate text using external API with caching"""
    # Return original text if languages are the same
    if source_lang == target_lang:
        return text

    # Check cache first
    cache_key = f"{source_lang}:{target_lang}:{text}"
    if cache_key in translation_cache:
        return translation_cache[cache_key]

    # Call translation API
    try:
        async with aiohttp.ClientSession() as session:
            async with session.post(
                TRANSLATION_API_URL,
                json={
                    "text": text,
                    "source": source_lang,
                    "target": target_lang
                },
                headers={"Authorization": f"Bearer {TRANSLATION_API_KEY}"}
            ) as response:
                if response.status == 200:
                    result = await response.json()
                    translated_text = result.get("translation", text)

                    # Cache the result
                    translation_cache[cache_key] = translated_text
                    return translated_text
                else:
                    # Log error and fall back to original text
                    print(f"Translation API error: {response.status}")
                    return text
    except Exception as e:
        print(f"Translation error: {str(e)}")
        return text

def get_language(
    accept_language: Optional[str] = Header(None),
    lang: Optional[str] = Query(None)
) -> str:
    """Determine the language based on query param or Accept-Language header"""
    # First check query parameter
    if lang and lang in SUPPORTED_LANGUAGES:
        return lang

    # Then check Accept-Language header
    if accept_language:
        for lang_item in accept_language.split(','):
            parts = lang_item.strip().split(';')
            lang_code = parts[0].split('-')[0].lower()
            if lang_code in SUPPORTED_LANGUAGES:
                return lang_code

    # Default fallback
    return DEFAULT_LANGUAGE

@app.get("/translate/{text}")
async def translate(text: str, target_lang: str = Depends(get_language)):
    translated = await translate_text(text, "en", target_lang)
    return {"original": text, "translated": translated, "language": target_lang}

```

```python
def negotiate_language(request: Request) -> str:
    """Determine language based on Accept-Language header"""
    accept_language = request.headers.get("Accept-Language", "")

    # Parse Accept-Language header and get best match
    if accept_language:
        languages = []
        for item in accept_language.split(','):
            parts = item.strip().split(';')
            lang = parts[0].split('-')[0].lower()

            # Extract quality factor (defaults to 1.0)
            quality = 1.0
            if len(parts) > 1 and parts[1].startswith('q='):
                try:
                    quality = float(parts[1][2:])
                except ValueError:
                    quality = 1.0

            languages.append((lang, quality))

        # Sort by quality factor (highest first)
        languages.sort(key=lambda x: x[1], reverse=True)

        # Find first supported language
        for lang, _ in languages:
            if lang in SUPPORTED_LANGUAGES:
                return lang

    return DEFAULT_LANGUAGE

async def get_product(product_id: int, language: str = Depends(negotiate_language)):
    # In a real app, fetch product by ID from database

    # Check if we have translations for this language
    if language not in product_data:
        language = DEFAULT_LANGUAGE

    product = product_data[language]
    return JSONResponse(

        headers={"Content-Language": language}
```

## Translation Management in FastAPI

For larger applications, you'll need a more structured approach to manage translations:

### Using a Translation Manager Class

```python
from fastapi import FastAPI, Depends, Header, Query, Request
from typing import Dict, List, Optional, Callable
import json
import os
from pathlib import Path

app = FastAPI()

class TranslationManager:
    def __init__(self, translations_dir: str, default_language: str = "en"):
        self.translations_dir = Path(translations_dir)
        self.default_language = default_language
        self.translations: Dict[str, Dict[str, str]] = {}
        self.available_languages: List[str] = []

        # Load translations
        self._load_translations()

    def _load_translations(self):
        """Load all translation files from the translations directory"""
        if not self.translations_dir.exists():
            print(f"Translations directory not found: {self.translations_dir}")
            return

        # Load each JSON translation file
        for file_path in self.translations_dir.glob("*.json"):
            lang_code = file_path.stem

            try:
                with open(file_path, "r", encoding="utf-8") as f:
                    translations = json.load(f)
                    self.translations[lang_code] = translations
                    self.available_languages.append(lang_code)
            except Exception as e:
                print(f"Error loading translations for {lang_code}: {str(e)}")

        print(f"Loaded translations for: {', '.join(self.available_languages)}")

    def get_language(self, request: Request) -> str:
        """Determine language from query param or Accept-Language header"""
        # First check query parameter
        lang = request.query_params.get("lang")
        if lang and lang in self.available_languages:
            return lang

        # Then check Accept-Language header
        accept_language = request.headers.get("Accept-Language")
        if accept_language:
            for lang_item in accept_language.split(','):
                parts = lang_item.strip().split(';')
                lang_code = parts[0].split('-')[0].lower()
                if lang_code in self.available_languages:
                    return lang_code

        # Default fallback
        return self.default_language

    def translate(self, key: str, language: str, **kwargs) -> str:
        """Translate a key to the specified language with variable replacement"""
        # Get translations for language
        translations = self.translations.get(language, {})

        # Look up the key
        if key in translations:
            text = translations[key]
        else:
            # Fallback to default language
            text = self.translations.get(self.default_language, {}).get(key, key)

        # Replace variables
        if kwargs:
            try:
                text = text.format(**kwargs)
            except KeyError as e:
                print(f"Missing placeholder in translation: {e}")

        return text

    def get_translator(self, language: str) -> Callable:
        """Get a translator function for a specific language"""
        def translator(key: str, **kwargs) -> str:
            return self.translate(key, language, **kwargs)
        return translator

# Initialize translation manager
translations_dir = os.path.join(os.path.dirname(__file__), "translations")
translation_manager = TranslationManager(translations_dir)

# Dependency to get translator for current request
async def get_translator(request: Request):
    language = translation_manager.get_language(request)
    return translation_manager.get_translator(language)

@app.get("/welcome/{name}")
async def welcome(name: str, translator: Callable = Depends(get_translator)):
    welcome_message = translator("welcome_message", name=name)
    return {"message": welcome_message}

@app.get("/about")
async def about(translator: Callable = Depends(get_translator)):
    return {
        "title": translator("about_title"),
        "content": translator("about_content"),
        "company": translator("company_name")
    }

```

## Localized Response Formatting

Beyond translating text, proper localization includes formatting dates, numbers, and currencies according to locale conventions:

```python
from fastapi import FastAPI, Depends, Request
from typing import Callable, Dict, Any
import datetime
import locale
import babel.numbers
import babel.dates
from babel.core import Locale

app = FastAPI()

# Mapping of language codes to locale identifiers
LOCALE_MAP = {
    "en": "en_US",
    "es": "es_ES",
    "fr": "fr_FR",
    "de": "de_DE",
    "ja": "ja_JP",
    "zh": "zh_CN"
}

def get_locale(request: Request) -> str:
    """Determine locale from query param or Accept-Language header"""
    # Check query parameter
    lang = request.query_params.get("lang")
    if lang and lang in LOCALE_MAP:
        return LOCALE_MAP[lang]

    # Check Accept-Language header
    accept_language = request.headers.get("Accept-Language")
    if accept_language:
        for lang_item in accept_language.split(','):
            parts = lang_item.strip().split(';')
            lang_code = parts[0].split('-')[0].lower()
            if lang_code in LOCALE_MAP:
                return LOCALE_MAP[lang_code]

    # Default fallback
    return LOCALE_MAP["en"]

class LocaleFormatter:
    def __init__(self, locale_str: str):
        self.locale_str = locale_str
        self.locale = Locale.parse(locale_str)

    def format_number(self, number: float) -> str:
        """Format a number according to locale conventions"""
        return babel.numbers.format_number(number, locale=self.locale_str)

    def format_currency(self, amount: float, currency: str = "USD") -> str:
        """Format a currency amount according to locale conventions"""
        return babel.numbers.format_currency(amount, currency, locale=self.locale_str)

    def format_date(self, date: datetime.date, format: str = "medium") -> str:
        """Format a date according to locale conventions"""
        return babel.dates.format_date(date, format=format, locale=self.locale_str)

    def format_time(self, time: datetime.time, format: str = "medium") -> str:
        """Format a time according to locale conventions"""
        return babel.dates.format_time(time, format=format, locale=self.locale_str)

    def format_datetime(self, dt: datetime.datetime, format: str = "medium") -> str:
        """Format a datetime according to locale conventions"""
        return babel.dates.format_datetime(dt, format=format, locale=self.locale_str)

# Dependency to get formatter for current request
async def get_formatter(request: Request) -> LocaleFormatter:
    locale_str = get_locale(request)
    return LocaleFormatter(locale_str)

@app.get("/product/{product_id}")
async def get_product(
    product_id: int,
    formatter: LocaleFormatter = Depends(get_formatter)
):
    # Mock product data
    price = 1299.99
    release_date = datetime.date(2023, 5, 15)

    return {
        "id": product_id,
        "name": "Smartphone Pro",
        "price": price,

        "release_date": release_date.isoformat(),
        "release_date_formatted": formatter.format_date(release_date)
    }

@app.get("/orders/{order_id}")

    # Mock order data

    shipping_date = datetime.datetime.now() - datetime.timedelta(days=1)

    # Mock items

    ]

    # Calculate totals
    subtotal = sum(item["price"] * item["quantity"] for item in items)
    tax = subtotal * 0.07
    total = subtotal + tax

    # Format items with localized currency
    formatted_items = []

    return {
        "order_id": order_id,

        "shipping_date": formatter.format_datetime(shipping_date),
        "items": formatted_items,
        "subtotal": formatter.format_currency(subtotal),
        "tax": formatter.format_currency(tax),
        "total": formatter.format_currency(total)
    }
```

## Integrating with Frontend Localization

When working with frontend applications, you might need to provide localized data for client-side rendering:

```python
    for lang_code in translations.keys():

            "code": lang_code,
            "name": autonym,
            "english_name": english_name
        })

    return {"languages": language_list}
```

## Handling Error Messages in Multiple Languages

```python
# Custom exception class with i18n support
class LocalizedHTTPException(HTTPException):
    def __init__(
        self,
        status_code: int,
        detail_key: str,
        **kwargs
    ):
        self.detail_key = detail_key
        self.kwargs = kwargs
        super().__init__(status_code=status_code, detail=detail_key)

# Exception handler for localized HTTP exceptions
@app.exception_handler(LocalizedHTTPException)
async def localized_exception_handler(request: Request, exc: LocalizedHTTPException):
    language = get_language(request)
    messages = ERROR_MESSAGES.get(language, ERROR_MESSAGES["en"])

    # Get error message from translations
    detail = messages.get(exc.detail_key, exc.detail_key)

    # Apply string formatting if kwargs provided
    if exc.kwargs:
        try:
            detail = detail.format(**exc.kwargs)
        except KeyError:
            pass

    return JSONResponse(
        status_code=exc.status_code,
        content={"error": detail},
        headers={"Content-Language": language}
    )

# Exception handler for validation errors
@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    language = get_language(request)
    messages = ERROR_MESSAGES.get(language, ERROR_MESSAGES["en"])
```

### 4. Implementing a Translation Loading Strategy

For applications with many languages and translations:

```python
from fastapi import FastAPI
import json
import os
from pathlib import Path
from typing import Dict, Any

app = FastAPI()

class TranslationManager:
    def __init__(self, translations_dir: str, lazy_load: bool = True):
        self.translations_dir = Path(translations_dir)
        self.translations: Dict[str, Dict[str, Any]] = {}
        self.available_languages = set()

        # Find available languages
        for lang_dir in self.translations_dir.iterdir():
            if lang_dir.is_dir():
                self.available_languages.add(lang_dir.name)

        # Load all translations immediately if not lazy loading
        if not lazy_load:
            for language in self.available_languages:
                self._load_language(language)

    def _load_language(self, language: str) -> Dict[str, Any]:
        """Load translations for a specific language"""
        if language in self.translations:
            return self.translations[language]

        language_path = self.translations_dir / language

        # Check if language directory exists
        if not language_path.exists() or not language_path.is_dir():
            return {}

        # Merge all JSON files in the language directory
        translations = {}
        for file_path in language_path.glob("*.json"):
            try:
                with open(file_path, "r", encoding="utf-8") as f:
                    file_translations = json.load(f)
                    translations.update(file_translations)
            except Exception as e:
                print(f"Error loading {file_path}: {str(e)}")

        # Cache the loaded translations
        self.translations[language] = translations
        return translations

    def get_translation(self, key: str, language: str, fallback_language: str = "en") -> Optional[str]:
        """Get a translation for a key in a specific language"""
        # Load language if not already loaded
        if language not in self.translations:
            self._load_language(language)

        # Try to get translation
        lang_translations = self.translations.get(language, {})
        if key in lang_translations:
            return lang_translations[key]

        # Try fallback language
        if language != fallback_language:
            if fallback_language not in self.translations:
                self._load_language(fallback_language)

            fallback_translations = self.translations.get(fallback_language, {})
            if key in fallback_translations:
                return fallback_translations[key]

        # No translation found
        return None

# Initialize translation manager
translation_manager = TranslationManager("./translations", lazy_load=True)
```

### 5. Content Negotiation with q-values

Respect quality values in Accept-Language header:

```python
from fastapi import FastAPI, Request
import re
from typing import List, Tuple, Dict

app = FastAPI()

def parse_accept_language(accept_language: str) -> List[Tuple[str, float]]:
    """Parse Accept-Language header with quality values"""
    if not accept_language:
        return []

    languages = []
    for item in accept_language.split(','):
        parts = item.strip().split(';q=')

        lang = parts[0].strip()
        # Get primary language code
        lang_code = lang.split('-')[0].lower()

        # Parse quality factor (default is 1.0)
        quality = 1.0
        if len(parts) > 1:
            try:
                q = float(parts[1])
                if 0 <= q <= 1:
                    quality = q
            except ValueError:
                pass

        languages.append((lang_code, quality))

    # Sort by quality factor (highest first)
    languages.sort(key=lambda x: x[1], reverse=True)
    return languages

def select_language(
    accept_language: str,
    supported_languages: List[str],
    default_language: str
) -> str:
    """Select best language based on Accept-Language header"""
    parsed_languages = parse_accept_language(accept_language)

    # Try to find a match in order of quality
    for lang, quality in parsed_languages:
        if lang in supported_languages:
            return lang

        # Try to find a partial match
        # For example, if user requests "en-US" but we only support "en"
        matches = [supported for supported in supported_languages if supported.startswith(lang)]
        if matches:
            return matches[0]

    # No match found, use default
    return default_language
```

```python
async def get_translation_quality(api_key: str = Depends(verify_admin)):
    """Get quality metrics for translations"""
    quality_metrics = {}

    for language, keys in translation_feedback.items():
        language_metrics = {
            "total_feedback": 0,
            "average_rating": 0,
            "keys_with_feedback": 0,
            "low_rated_keys": []
        }

        total_ratings = 0
        rating_sum = 0

        for key, feedback_list in keys.items():
            if not feedback_list:
                continue

            # Count feedback for this key
            key_ratings = [fb["rating"] for fb in feedback_list if "rating" in fb]
            if not key_ratings:
                continue

            key_avg = sum(key_ratings) / len(key_ratings)
            total_ratings += len(key_ratings)
            rating_sum += sum(key_ratings)

            language_metrics["keys_with_feedback"] += 1

            # Track low-rated keys
            if key_avg < 3:
                language_metrics["low_rated_keys"].append({
                    "key": key,
                    "average_rating": key_avg,
                    "feedback_count": len(key_ratings)
                })

        # Calculate overall metrics
        language_metrics["total_feedback"] = total_ratings
        if total_ratings > 0:
            language_metrics["average_rating"] = rating_sum / total_ratings

        quality_metrics[language] = language_metrics

    return quality_metrics
```
