# 8.3 Error Handling and Validation

## Introduction to Error Handling in FastAPI

Proper error handling is essential for building robust and user-friendly APIs. FastAPI provides several mechanisms for handling errors and validation failures in a consistent and clean way.

### Why Error Handling is Important

- **User Experience**: Clear error messages help API users understand what went wrong
- **Security**: Proper error handling prevents leaking sensitive information
- **Debugging**: Well-structured errors make troubleshooting easier
- **Consistency**: Standardized error responses make client integration simpler
- **Reliability**: Graceful error handling prevents application crashes

## Global Exception Handlers

FastAPI allows you to define custom exception handlers that catch specific types of exceptions and return appropriate responses.

### Default Exception Handling

By default, FastAPI already handles many common exceptions:

1. `RequestValidationError`: When request data fails validation
2. `HTTPException`: For explicitly raised HTTP errors
3. Other exceptions: Converted to 500 Internal Server Error

### Creating Custom Exception Handlers

```python
from fastapi import FastAPI, Request, HTTPException
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException
import time

app = FastAPI()

@app.exception_handler(StarletteHTTPException)
async def http_exception_handler(request: Request, exc: StarletteHTTPException):
    return JSONResponse(
        status_code=exc.status_code,
        content={
            "status": "error",
            "code": exc.status_code,
            "message": exc.detail,
            "timestamp": int(time.time())
        }
    )

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    errors = []
    for error in exc.errors():
        error_loc = " -> ".join([str(loc) for loc in error["loc"]])
        errors.append({
            "location": error_loc,
            "message": error["msg"],
            "type": error["type"]
        })

    return JSONResponse(
        status_code=422,
        content={
            "status": "error",
            "code": 422,
            "message": "Validation error",
            "errors": errors,
            "timestamp": int(time.time())
        }
    )

@app.exception_handler(Exception)
async def general_exception_handler(request: Request, exc: Exception):
    # Log the exception details here

    return JSONResponse(
        status_code=500,
        content={
            "status": "error",
            "code": 500,
            "message": "An unexpected error occurred",
            "timestamp": int(time.time())
        }
    )

# Example endpoints that might raise errors
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id == 999:
        raise HTTPException(status_code=404, detail="Item not found")
    if item_id < 0:
        raise ValueError("Invalid item ID")
    return {"item_id": item_id}

```

## Creating Custom Exceptions

You can create custom exception classes for specific error scenarios in your application:

```python
from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse
import time

app = FastAPI()

# Custom exception classes
class RateLimitExceeded(Exception):
    def __init__(self, retry_after: int):
        self.retry_after = retry_after
        self.message = f"Rate limit exceeded. Try again in {retry_after} seconds."
        super().__init__(self.message)

class AuthenticationError(Exception):
    def __init__(self, message: str = "Authentication failed"):
        self.message = message
        super().__init__(self.message)

class ResourceNotFoundError(Exception):
    def __init__(self, resource_type: str, resource_id: str):
        self.resource_type = resource_type
        self.resource_id = resource_id
        self.message = f"{resource_type} with ID {resource_id} not found"
        super().__init__(self.message)

# Exception handlers for custom exceptions
@app.exception_handler(RateLimitExceeded)
async def rate_limit_exception_handler(request: Request, exc: RateLimitExceeded):
    return JSONResponse(
        status_code=429,
        content={
            "status": "error",
            "code": 429,
            "message": exc.message,
            "timestamp": int(time.time())
        },
        headers={"Retry-After": str(exc.retry_after)}
    )

@app.exception_handler(AuthenticationError)
async def auth_exception_handler(request: Request, exc: AuthenticationError):
    return JSONResponse(
        status_code=401,
        content={
            "status": "error",
            "code": 401,
            "message": exc.message,
            "timestamp": int(time.time())
        }
    )

@app.exception_handler(ResourceNotFoundError)
async def not_found_exception_handler(request: Request, exc: ResourceNotFoundError):
    return JSONResponse(
        status_code=404,
        content={
            "status": "error",
            "code": 404,
            "message": exc.message,
            "resource_type": exc.resource_type,
            "resource_id": exc.resource_id,
            "timestamp": int(time.time())
        }
    )

# Example endpoints that use custom exceptions
@app.get("/users/{user_id}")
async def get_user(user_id: str):
    if user_id == "missing":
        raise ResourceNotFoundError("User", user_id)
    if user_id == "too-many-requests":
        raise RateLimitExceeded(30)
    if user_id == "unauthorized":
        raise AuthenticationError("Invalid or expired token")
    return {"user_id": user_id, "name": "John Doe"}

```

## Validation Error Handling

FastAPI uses Pydantic for data validation, which provides rich validation error information.

### Customizing Validation Error Responses

```python
from fastapi import FastAPI, Request, Body
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from pydantic import BaseModel, Field, validator, EmailStr

app = FastAPI()

# Define model with custom validation
class User(BaseModel):
    username: str = Field(..., min_length=3, max_length=50)
    email: EmailStr
    age: int = Field(..., gt=0, lt=120)

    @validator("username")
    def username_alphanumeric(cls, v):
        if not v.isalnum():
            raise ValueError("must be alphanumeric")
        return v

# Custom validation error handler
@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request: Request, exc: RequestValidationError):
    # Extract errors from the validation exception
    errors = {}
    for error in exc.errors():
        error_field = error["loc"][-1] if error["loc"] else "data"
        if error_field not in errors:
            errors[error_field] = []
        errors[error_field].append(error["msg"])

    # Create a user-friendly response
    return JSONResponse(
        status_code=422,
        content={
            "status": "error",
            "message": "Validation failed",
            "errors": errors
        }
    )

@app.post("/users/")
async def create_user(user: User):
    return {"user": user.dict(), "message": "User created successfully"}

```

```python
from datetime import datetime

class Product(BaseModel):

    name: str
    price: float

    def set_created_at(cls, v):
        return v or datetime.now()
```

## Error Response Standardization

Consistent error response formats make it easier for clients to handle errors:

```python
from fastapi import FastAPI, HTTPException, Request, status
from fastapi.responses import JSONResponse
from pydantic import BaseModel
from typing import Optional, Any, Dict, List
import time

app = FastAPI()

# Define standard error response model
class ErrorResponse(BaseModel):
    status: str = "error"
    code: int
    message: str
    details: Optional[Any] = None
    timestamp: int

# Custom middleware for error handling
@app.middleware("http")
async def error_handling_middleware(request: Request, call_next):
    try:
        return await call_next(request)
    except Exception as exc:
        # This will catch exceptions that weren't handled by specific exception handlers
        status_code = 500
        message = "Internal server error"

        # Set appropriate status based on exception type
        if isinstance(exc, HTTPException):
            status_code = exc.status_code
            message = exc.detail

        error = ErrorResponse(
            code=status_code,
            message=message,
            timestamp=int(time.time())
        )

        return JSONResponse(
            status_code=status_code,
            content=error.dict()
        )

# Function to create standardized HTTP exceptions
def create_error(status_code: int, message: str, details: Any = None) -> HTTPException:
    return HTTPException(
        status_code=status_code,
        detail=message,
        headers={"X-Error-Details": str(details) if details else ""}
    )

# Errors module for common errors
class Errors:
    @staticmethod
    def not_found(resource: str, resource_id: str) -> HTTPException:
        return create_error(
            status.HTTP_404_NOT_FOUND,
            f"{resource} with ID {resource_id} not found"
        )

    @staticmethod
    def unauthorized(message: str = "Authentication required") -> HTTPException:
        return create_error(
            status.HTTP_401_UNAUTHORIZED,
            message
        )

    @staticmethod
    def forbidden(message: str = "Permission denied") -> HTTPException:
        return create_error(
            status.HTTP_403_FORBIDDEN,
            message
        )

    @staticmethod
    def bad_request(message: str, details: Any = None) -> HTTPException:
        return create_error(
            status.HTTP_400_BAD_REQUEST,
            message,
            details
        )

# Example usage
@app.get("/items/{item_id}")
async def get_item(item_id: str):
    if item_id == "missing":
        raise Errors.not_found("Item", item_id)
    if item_id == "unauthorized":
        raise Errors.unauthorized("You must be logged in to access this item")
    if item_id == "forbidden":
        raise Errors.forbidden("You don't have permission to access this item")
    if item_id == "bad":
        raise Errors.bad_request(
            "Invalid query parameters",
            {"details": "Sort parameter must be one of: name, price, date"}
        )

    # Normal response
    return {"item_id": item_id, "name": "Example Item"}

```

### Advanced Validation with Pydantic

```python
from pydantic import BaseModel, Field, validator, root_validator
from typing import List, Optional, Dict, Any
from datetime import datetime
import re

class Address(BaseModel):
    street: str
    city: str
    state: str
    zip_code: str
    country: str = "USA"

    @validator("zip_code")
    def validate_zip_code(cls, v, values):
        country = values.get("country")
        if country == "USA" and not re.match(r"^\d{5}(-\d{4})?$", v):
            raise ValueError("Invalid US ZIP code format")
        return v

class CreditCard(BaseModel):
    number: str
    expiration_month: int = Field(..., ge=1, le=12)
    expiration_year: int = Field(..., ge=2022)
    security_code: str = Field(..., min_length=3, max_length=4)

    @validator("number")
    def validate_cc_number(cls, v):
        # Remove spaces and dashes
        v = v.replace(" ", "").replace("-", "")

        # Check if it's only digits
        if not v.isdigit():
            raise ValueError("Credit card must contain only digits")

        # Check length (most cards are 13-19 digits)
        if not 13 <= len(v) <= 19:
            raise ValueError("Credit card number has invalid length")

        # Luhn algorithm to validate card number
        digits = [int(d) for d in v]
        checksum = 0
        for i, digit in enumerate(reversed(digits)):
            if i % 2 == 1:  # Odd positions (from right)
                digit *= 2
                if digit > 9:
                    digit -= 9
            checksum += digit

        if checksum % 10 != 0:
            raise ValueError("Invalid credit card number")

        # Mask card number except for last 4 digits
        return "*" * (len(v) - 4) + v[-4:]

    @validator("expiration_year", "expiration_month")
    def validate_expiration(cls, v, values, **kwargs):
        field = kwargs.get("field")

        # Skip validation if previous fields had errors
        if values.get("expiration_month") is None and field.name == "expiration_year":
            return v

        if "expiration_year" in values and field.name == "expiration_month":
            exp_year = values["expiration_year"]
            exp_month = v

            current_year = datetime.now().year
            current_month = datetime.now().month

            if exp_year == current_year and exp_month < current_month:
                raise ValueError("Card has expired")

        return v

    # Mask security code
    @validator("security_code")
    def mask_security_code(cls, v):
        return "*" * len(v)

class Order(BaseModel):
    id: str
    items: List[Dict[str, Any]]
    user_id: str
    total_amount: float
    shipping_address: Address
    billing_address: Optional[Address] = None
    payment_method: Optional[CreditCard] = None

    @validator("id")
    def validate_order_id(cls, v):
        if not re.match(r"^ORD-\d{8}$", v):
            raise ValueError("Order ID must have format ORD-XXXXXXXX where X is a digit")
        return v

    @validator("items")
    def validate_items(cls, v):
        if not v:
            raise ValueError("Order must contain at least one item")

        for i, item in enumerate(v):
            if "product_id" not in item:
                raise ValueError(f"Item at position {i} missing product_id")
            if "quantity" not in item:
                raise ValueError(f"Item at position {i} missing quantity")
            if "price" not in item:
                raise ValueError(f"Item at position {i} missing price")

            # Convert quantity to int
            item["quantity"] = int(item["quantity"])
            if item["quantity"] <= 0:
                raise ValueError(f"Item at position {i} has invalid quantity")

            # Convert price to float
            item["price"] = float(item["price"])
            if item["price"] < 0:
                raise ValueError(f"Item at position {i} has invalid price")

        return v

    @root_validator
    def validate_addresses(cls, values):
        shipping_addr = values.get("shipping_address")
        billing_addr = values.get("billing_address")

        # If billing address not provided, use shipping address
        if not billing_addr and shipping_addr:
            values["billing_address"] = shipping_addr

        return values

    @root_validator
    def validate_total_amount(cls, values):
        items = values.get("items", [])
        calculated_total = sum(item.get("price", 0) * item.get("quantity", 0) for item in items)

        total_amount = values.get("total_amount")
        if total_amount is not None and abs(total_amount - calculated_total) > 0.01:
            raise ValueError(f"Total amount {total_amount} doesn't match calculated amount {calculated_total}")

        return values

@app.post("/orders/")
async def create_order(order: Order):
    # Order processing logic here
    return {"order_id": order.id, "status": "created"}

```

## Error Logging and Monitoring

Proper error logging is essential for debugging and monitoring your application:

```python
from fastapi import FastAPI, Request, HTTPException
from fastapi.responses import JSONResponse
import logging
import time
import traceback
import uuid
from typing import Optional, Dict, Any

# Setup logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger("app")

# Add file handler
file_handler = logging.FileHandler("errors.log")
file_handler.setLevel(logging.ERROR)
formatter = logging.Formatter(
    "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
file_handler.setFormatter(formatter)
logger.addHandler(file_handler)

app = FastAPI()

# Middleware to log requests and errors
@app.middleware("http")
async def log_requests(request: Request, call_next):
    start_time = time.time()
    request_id = str(uuid.uuid4())

    # Add request ID to request state for access in endpoints
    request.state.request_id = request_id

    # Log request details
    logger.info(
        f"Request started - ID: {request_id} - Method: {request.method} - "
        f"Path: {request.url.path} - Client: {request.client.host}"
    )

    try:
        # Process request
        response = await call_next(request)

        # Log successful response
        process_time = time.time() - start_time
        logger.info(
            f"Request completed - ID: {request_id} - Status: {response.status_code} - "
            f"Time: {process_time:.4f}s"
        )

        # Add request ID to response headers
        response.headers["X-Request-ID"] = request_id
        return response

    except Exception as e:
        # Log the error with full traceback
        process_time = time.time() - start_time
        logger.error(
            f"Request failed - ID: {request_id} - Error: {str(e)} - "
            f"Time: {process_time:.4f}s"
        )
        logger.error(f"Traceback: {traceback.format_exc()}")

        # Return error response
        error_response = {
            "status": "error",
            "message": "Internal server error",
            "request_id": request_id
        }

        # Only include error details in development
        if app.debug:
            error_response["error"] = str(e)
            error_response["traceback"] = traceback.format_exc().split("\n")

        return JSONResponse(
            status_code=500,
            content=error_response,
            headers={"X-Request-ID": request_id}
        )

# Function to log errors with context
def log_error(
    exc: Exception,
    request: Optional[Request] = None,
    context: Optional[Dict[str, Any]] = None
):
    error_data = {
        "error_type": exc.__class__.__name__,
        "error_message": str(exc),
        "traceback": traceback.format_exc()
    }

    if request:
        error_data.update({
            "method": request.method,
            "url": str(request.url),
            "client_ip": request.client.host,
            "request_id": getattr(request.state, "request_id", None)
        })

    if context:
        error_data.update(context)

    logger.error(f"Error occurred: {error_data}")
    return error_data

# Example endpoint with error logging
@app.get("/items/{item_id}")
async def get_item(item_id: int, request: Request):
    try:
        # Simulate an error
        if item_id == 999:
            raise ValueError("Item with this ID is not processable")

        # Normal response
        return {"item_id": item_id, "name": "Example Item"}

    except ValueError as e:
        # Log with context
        error_info = log_error(
            e,
            request,
            {"item_id": item_id, "additional_info": "This item has special handling"}
        )

        # Raise HTTP exception with request ID
        raise HTTPException(
            status_code=400,
            detail=f"Invalid item ID: {str(e)}",
            headers={"X-Request-ID": request.state.request_id}
        )

```

## Creating a Comprehensive Error Handling System

Let's build a complete error handling system that combines all the techniques:

```python
from fastapi import FastAPI, Request, HTTPException, Depends, status
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from pydantic import BaseModel, Field, ValidationError
from typing import Optional, Any, Dict, List, Type
from enum import Enum
import time
import logging
import traceback
import uuid
import json

# Setup logging
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger("app")

# Create app with debug mode
app = FastAPI(debug=True)

# Error code enum
class ErrorCode(str, Enum):
    VALIDATION_ERROR = "VALIDATION_ERROR"
    AUTHENTICATION_ERROR = "AUTHENTICATION_ERROR"
    PERMISSION_ERROR = "PERMISSION_ERROR"
    RESOURCE_NOT_FOUND = "RESOURCE_NOT_FOUND"
    RESOURCE_ALREADY_EXISTS = "RESOURCE_ALREADY_EXISTS"
    RATE_LIMIT_EXCEEDED = "RATE_LIMIT_EXCEEDED"
    INVALID_REQUEST = "INVALID_REQUEST"
    INTERNAL_ERROR = "INTERNAL_ERROR"

# Standard error response model
class ErrorResponse(BaseModel):
    status: str = "error"
    code: ErrorCode
    message: str
    details: Optional[Any] = None
    request_id: Optional[str] = None
    timestamp: int = Field(default_factory=lambda: int(time.time()))

# Custom exceptions
class APIError(Exception):
    def __init__(
        self,
        code: ErrorCode,
        message: str,
        status_code: int = 400,
        details: Any = None
    ):
        self.code = code
        self.message = message
        self.status_code = status_code
        self.details = details
        super().__init__(self.message)

class ResourceNotFound(APIError):
    def __init__(self, resource: str, resource_id: str):
        super().__init__(
            code=ErrorCode.RESOURCE_NOT_FOUND,
            message=f"{resource} with ID {resource_id} not found",
            status_code=404,
            details={"resource": resource, "id": resource_id}
        )

class AuthenticationError(APIError):
    def __init__(self, message: str = "Authentication failed"):
        super().__init__(
            code=ErrorCode.AUTHENTICATION_ERROR,
            message=message,
            status_code=401
        )

class PermissionError(APIError):
    def __init__(self, message: str = "Permission denied"):
        super().__init__(
            code=ErrorCode.PERMISSION_ERROR,
            message=message,
            status_code=403
        )

class RateLimitError(APIError):
    def __init__(self, message: str = "Rate limit exceeded", retry_after: int = 60):
        self.retry_after = retry_after
        super().__init__(
            code=ErrorCode.RATE_LIMIT_EXCEEDED,
            message=message,
            status_code=429,
            details={"retry_after": retry_after}
        )

class ResourceExists(APIError):
    def __init__(self, resource: str, identifier: Dict[str, Any]):
        super().__init__(
            code=ErrorCode.RESOURCE_ALREADY_EXISTS,
            message=f"{resource} already exists with the provided identifier",
            status_code=409,
            details={"resource": resource, "identifier": identifier}
        )

# Exception handler for API errors
@app.exception_handler(APIError)
async def api_error_handler(request: Request, exc: APIError):
    # Log error
    log_error(exc, request)

    # Create error response
    error = ErrorResponse(
        code=exc.code,
        message=exc.message,
        details=exc.details,
        request_id=getattr(request.state, "request_id", None)
    )

    # Headers
    headers = {}
    if isinstance(exc, RateLimitError):
        headers["Retry-After"] = str(exc.retry_after)

    return JSONResponse(
        status_code=exc.status_code,
        content=error.dict(),
        headers=headers
    )

# Exception handler for validation errors
@app.exception_handler(RequestValidationError)
async def validation_error_handler(request: Request, exc: RequestValidationError):
    # Log error
    log_error(exc, request)

    # Format validation errors
    error_details = []
    for err in exc.errors():
        error_loc = " -> ".join([str(loc) for loc in err["loc"]])
        error_details.append({
            "location": error_loc,
            "type": err["type"],
            "message": err["msg"]
        })

    # Create error response
    error = ErrorResponse(
        code=ErrorCode.VALIDATION_ERROR,
        message="Request validation failed",
        details=error_details,
        request_id=getattr(request.state, "request_id", None)
    )

    return JSONResponse(
        status_code=422,
        content=error.dict()
    )

# Exception handler for HTTP exceptions
@app.exception_handler(HTTPException)
async def http_exception_handler(request: Request, exc: HTTPException):
    # Log error
    log_error(exc, request)

    # Map status code to error code
    code_map = {
        400: ErrorCode.INVALID_REQUEST,
        401: ErrorCode.AUTHENTICATION_ERROR,
        403: ErrorCode.PERMISSION_ERROR,
        404: ErrorCode.RESOURCE_NOT_FOUND,
        409: ErrorCode.RESOURCE_ALREADY_EXISTS,
        429: ErrorCode.RATE_LIMIT_EXCEEDED
    }

    error_code = code_map.get(exc.status_code, ErrorCode.INTERNAL_ERROR)

    # Create error response
    error = ErrorResponse(
        code=error_code,
        message=exc.detail,
        request_id=getattr(request.state, "request_id", None)
    )

    return JSONResponse(
        status_code=exc.status_code,
        content=error.dict(),
        headers=exc.headers
    )

# Exception handler for all other exceptions
@app.exception_handler(Exception)
async def general_exception_handler(request: Request, exc: Exception):
    # Log error
    log_error(exc, request)

    # Create error response
    error = ErrorResponse(
        code=ErrorCode.INTERNAL_ERROR,
        message="An unexpected error occurred",
        request_id=getattr(request.state, "request_id", None)
    )

    # Include detailed error info in development mode
    if app.debug:
        error.details = {
            "error_type": exc.__class__.__name__,
            "error": str(exc),
            "traceback": traceback.format_exc().split("\n")
        }

    return JSONResponse(
        status_code=500,
        content=error.dict()
    )
```

```python
    # Group errors by field

    for error in exc.errors():
        # Get field name (last part of location)
        field_name = error["loc"][-1] if error["loc"] else "data"

        # For nested fields, join with dots
        if len(error["loc"]) > 1:

            parts = error["loc"][1:] if error["loc"][0] in ("body", "query", "path") else error["loc"]

        if field_name not in error_map:

        error_map[field_name].append(error["msg"])

    return JSONResponse(
        status_code=422,
        content={
            "status": "error",
            "message": "Validation error",
            "errors": error_map
        }
```

```python
            # Format for output
            return f"{digits_only[0:5]} {digits_only[5:]}"

        return v
```

```python

from fastapi.responses import JSONResponse

    "image/png",
    "image/gif",
    "application/pdf"

    file_size = 0
    contents = await file.read(MAX_FILE_SIZE + 1)  # Read one byte more to check if it exceeds
    file_size = len(contents)

    # Reset file position for later operations
    await file.seek(0)

    if file_size > MAX_FILE_SIZE:
        raise HTTPException(
            status_code=413,  # Payload Too Large
            detail=f"File size exceeds maximum allowed size of {MAX_FILE_SIZE // 1024 // 1024}MB"

    if mime_type not in ALLOWED_MIME_TYPES:
        raise HTTPException(
            status_code=415,  # Unsupported Media Type
            detail=f"File type '{mime_type}' not allowed. Allowed types: {', '.join(ALLOWED_MIME_TYPES)}"
```

### 1. Consistent Error Response Format

### 3. Use Appropriate HTTP Status Codes

| Status Code | Description           | When to Use                          |
| ----------- | --------------------- | ------------------------------------ |
| 400         | Bad Request           | Invalid input, malformed request     |
| 401         | Unauthorized          | Missing or invalid authentication    |
| 403         | Forbidden             | Authenticated but not authorized     |
| 404         | Not Found             | Resource does not exist              |
| 409         | Conflict              | Resource already exists or conflicts |
| 422         | Unprocessable Entity  | Validation errors                    |
| 429         | Too Many Requests     | Rate limit exceeded                  |
| 500         | Internal Server Error | Unexpected server errors             |

### 4. Include Request IDs for Troubleshooting

Add a unique identifier to each request to help correlate errors across systems:
