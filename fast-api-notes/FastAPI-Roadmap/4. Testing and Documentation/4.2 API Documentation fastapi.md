# 4.2 API Documentation in FastAPI

## Overview

FastAPI automatically generates interactive API documentation using OpenAPI (formerly Swagger) specification. This documentation is live, interactive, and always up-to-date with your code.

## Automatic Documentation Features

### Built-in Documentation UIs

FastAPI provides two automatic documentation interfaces:

1. **Swagger UI** - Available at `/docs`

   - Interactive API explorer
   - Test endpoints directly from browser
   - Request/response examples
   - Parameter validation

2. **ReDoc** - Available at `/redoc`
   - Clean, professional documentation
   - Better for reading and sharing
   - Organized endpoint grouping
   - Downloadable OpenAPI schema

### OpenAPI Schema

- **JSON Schema**: Available at `/openapi.json`
- **Automatic Generation**: Based on your Python type hints
- **Standard Compliance**: Follows OpenAPI 3.0+ specification
- **Client SDK Generation**: Can generate client libraries

## Pydantic Models for Documentation

### Model Examples

```python
from pydantic import BaseModel, Field
from typing import Optional

class UserCreate(BaseModel):
    name: str = Field(..., example="John Doe", description="User's full name")
    email: str = Field(..., example="john@example.com", description="Valid email address")
    age: Optional[int] = Field(None, ge=0, le=120, example=25, description="User's age")

    class Config:
        schema_extra = {
            "example": {
                "name": "John Doe",
                "email": "john@example.com",
                "age": 25
            }
        }
```

### Field Documentation

- **Field()**: Add descriptions, examples, constraints
- **example**: Shows in documentation as sample value
- **description**: Explains the field purpose
- **title**: Custom field title in docs

## Advanced Documentation Features

Organize endpoints into logical groups:


## Documentation Customization

### Custom OpenAPI Schema

```python
def custom_openapi():
    if app.openapi_schema:
        return app.openapi_schema

    openapi_schema = get_openapi(
        title="Custom API",
        version="2.5.0",
        description="This is a custom OpenAPI schema",
        routes=app.routes,
    )

    # Add custom fields
    openapi_schema["info"]["x-logo"] = {
        "url": "https://example.com/logo.png"
    }

    app.openapi_schema = openapi_schema
    return app.openapi_schema

app.openapi = custom_openapi
```

### Disabling Documentation

```python
# Disable in production
app = FastAPI(docs_url=None, redoc_url=None)

# Or conditionally disable
import os
docs_url = "/docs" if os.getenv("ENVIRONMENT") != "production" else None
app = FastAPI(docs_url=docs_url)
```

## Error Documentation

### Custom Exception Documentation

```python
class ItemNotFoundException(HTTPException):
    def __init__(self, item_id: int):
        super().__init__(
            status_code=404,
            detail=f"Item {item_id} not found"
        )

@app.exception_handler(ItemNotFoundException)
async def item_not_found_handler(request, exc):
    return JSONResponse(
        status_code=exc.status_code,
        content={"message": exc.detail}
    )
```

## Documentation Best Practices

### Clear Descriptions

- Write clear, concise endpoint descriptions
- Explain what each parameter does
- Document expected behavior
- Include examples for complex objects

### Logical Organization

- Use tags to group related endpoints
- Order endpoints logically
- Use consistent naming conventions
- Group by resource or functionality

### Complete Information

- Document all possible responses
- Include error scenarios
- Provide request/response examples
- Document authentication requirements

### Professional Presentation

- Add company/API information
- Include contact details
- Add terms of service links
- Use consistent formatting

## Advanced Documentation Patterns

### Versioning Documentation

```python
from fastapi import APIRouter

v1_router = APIRouter(prefix="/v1", tags=["v1"])
v2_router = APIRouter(prefix="/v2", tags=["v2"])

@v1_router.get("/users")
async def get_users_v1():
    pass

@v2_router.get("/users")
async def get_users_v2():
    pass

app.include_router(v1_router)
app.include_router(v2_router)
```

### External Documentation Links

```python
@app.get(
    "/complex-endpoint",
    tags=["advanced"],
    responses={
        200: {

            "content": {
                "application/json": {
                    "example": {"result": "success"}
                }
            }
        }
    }

async def complex_endpoint():

    Complex endpoint that requires additional documentation.

    For more details, see: https://docs.example.com/complex-endpoint

```

### Conditional Documentation

```python
def get_settings():
    return {"show_docs": True, "environment": "development"}

settings = get_settings()

app = FastAPI(
    docs_url="/docs" if settings["show_docs"] else None,
    redoc_url="/redoc" if settings["show_docs"] else None
)
```
