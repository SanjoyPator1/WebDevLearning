# FastAPI Book Management System Project

## Project Overview

In this project, you will build a Book Management System using FastAPI. This project is designed to help you practice the fundamental concepts of FastAPI that you've learned in your notes, including route definitions, path operations, request/response models, and Pydantic data validation.

## Project Requirements

### 1. Set Up Development Environment

- Create a virtual environment for the project
- Install FastAPI and Uvicorn
- Set up a basic project structure following the organization principles from your notes

### 2. Create the FastAPI Application

- Create a main application file
- Configure the FastAPI app with appropriate title, description, and version
- Implement a basic health check endpoint at the root route ("/")

### 3. Define Data Models

Create the following Pydantic models:

- `Book`: Representing a book with fields:
  - id (integer)
  - title (string)
  - author (string)
  - description (optional string)
  - publication_year (integer)
  - price (float)
  - isbn (string)
- `BookCreate`: Used for creating a new book (without id)
- `BookUpdate`: Used for updating an existing book (with optional fields)

### 4. Implement CRUD Operations

Implement the following API endpoints:

- `GET /books`: List all books with optional filtering by author and publication year
  - Include pagination with `skip` and `limit` query parameters
- `GET /books/{book_id}`: Get details of a specific book
- `POST /books`: Add a new book
- `PUT /books/{book_id}`: Update a book
- `DELETE /books/{book_id}`: Delete a book

### 5. Add Data Validation

Implement validation for:

- Book title (min length 1, max length 100)
- Price (greater than 0)
- Publication year (between 1900 and current year)
- ISBN (format validation using regex or length check)
- Use Pydantic validators to implement these validations

### 6. Enhance Response Handling

- Implement proper status codes for different operations:
  - 201 (Created) for POST operations
  - 204 (No Content) for DELETE operations
  - 200 (OK) for successful GET and PUT operations
- Add error handling for common scenarios:
  - 404 for book not found
  - 400 for validation errors
- Use response models to control the output schema

### 7. Implement Additional Features (Optional)

- Add a search endpoint (`GET /books/search/`) that allows searching books by title or author
- Implement advanced pagination for the list endpoint with next/previous page links
- Add a rating system for books
- Implement sorting options for book listings

## Project Structure

Create a well-organized project structure:

```
fastapi-book-management/
│
├── app/                    # Application package
│   ├── __init__.py
│   ├── main.py            # FastAPI application
│   └── models.py          # Pydantic models
│
├── venv/                   # Virtual environment (not tracked in git)
├── .gitignore
├── README.md
└── requirements.txt

```

## Testing Your API

After implementing your application:

1. Run your FastAPI application using Uvicorn
2. Open your browser and navigate to `http://localhost:8000/docs` to see the interactive API documentation
3. Test your endpoints directly from the Swagger UI
4. Use a tool like Postman or curl to make requests to your API

By completing this project, you will practice:

- Defining data models with Pydantic
- Implementing CRUD operations
- Working with path and query parameters
- Validating request data
- Using response models
