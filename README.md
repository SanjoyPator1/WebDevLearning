# WebDevLearning: NestJS

Learning NestJS from scratch again (restarted November 2026, on NestJS 12).

Start with the roadmap: [docs/01_nestjs_roadmap.md](docs/01_nestjs_roadmap.md).

## Layout

- `docs/`: the knowledge hub for documents that cut across topics. Holds the roadmap and the side projects guide.
- `notes/`: the study notes, one folder per phase and one file per topic.
- `projects/`: roadmap exercises for each phase. Each one has three folders:
  - `template/`: the unsolved starter.
  - `solution/`: your work.
  - `solved/`: the reference answer.
- `side_projects/`: your own projects, outside the roadmap. One standalone folder per project, with no phases and no `template/solution/solved`. See [docs/03_side_projects.md](docs/03_side_projects.md).
- `scripts/start_exercise.sh`: copies an exercise's `template/` into `solution/`.
- `archive/`: old work kept for reference. It is not maintained.

The full conventions for exercises are in the roadmap's Repository Layout and Exercise Workflow sections.
