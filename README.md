# React Interview Practice

This repository contains my practice work for React interviews, organized into two separate collections of tasks.

## Repository Structure

- **set-01-frontend-focused**: Progressive React practice tasks focused on frontend implementation, organized by difficulty level and component patterns.
- **set-02-topic-based**: Practice tasks organized by topic following Brian Holt's React v9 course structure from Frontend Masters.

## Getting Started

Each folder contains its own React project with separate dependencies and tasks:

```bash
# For frontend-focused tasks
cd set-01-frontend-focused
npm install
npm run dev

# For topic-based tasks
cd set-02-topic-based
npm install
npm run dev
```
