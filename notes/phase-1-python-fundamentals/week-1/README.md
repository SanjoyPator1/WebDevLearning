## How to Use This Week's Materials

### 1. Read the Daily Notes
Start each day by reading the corresponding markdown file. Take your time to understand the concepts.

### 2. Run the Code Examples
```bash
cd code-examples/
python 01_decorators_basic.py
python 02_decorators_advanced.py
# ... and so on
```

### 3. Experiment in Notebooks (Optional)
```bash
jupyter notebook notebooks/decorators_exploration.ipynb
```

### 4. Complete the Exercises
```bash
cd ../../exercises/python-fundamentals/decorators/
# Read EXERCISES.md
# Complete each exercise_X.py file
python exercise_1.py
```

### 5. Save Your Solutions
```bash
# Move completed exercises to solutions folder
cp exercise_1.py solutions/exercise_1_solution.py
```
