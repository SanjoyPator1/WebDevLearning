Real-world authentication pattern:

  • User submits credentials

Cookie Scope Testing

Understanding Cookie Scope:

  • Domain: Which sites can receive this cookie
  • Path: Which URLs can use this cookie
  • Rule: Cookie sent ONLY if both domain AND path match
  • Common Bug: Cookie exists but isn't sent due to path mismatch

Live Cookie Viewer

Note: HttpOnly cookies are not accessible via JavaScript (by design for security).

To view HttpOnly cookies:

  1. Open DevTools (F12)
  2. Go to Application tab
  3. Expand Cookies in left sidebar
  4. Click on http://localhost:8000

How to Test with DevTools

Step-by-step testing:

  1. Open browser DevTools (F12)
  2. Go to Application tab
  3. Find Cookies in left sidebar
  4. Click on http://localhost:8000
  5. Click "Login" button above
  6. Watch new cookie appear in DevTools
  7. Check the flags: HttpOnly, Secure, SameSite, Path
  8. Switch to Network tab
  9. Click "Access Protected Route" button
  10. Click on the request in Network tab
  11. Check Request Headers → see Cookie being sent
