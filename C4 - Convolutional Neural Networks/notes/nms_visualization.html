🔍 Non-Maximum Suppression (NMS)

Interactive visualization for eliminating duplicate detections

1. The Multiple Detection Problem

Problem: Object detection algorithms often detect the same object multiple times with different confidence scores and slightly different bounding boxes.

Solution: NMS keeps only the highest confidence detection and suppresses overlapping duplicates.

3. NMS Algorithm Steps

1
Filter Low Confidence
Remove all detections with confidence score below threshold (e.g., < 0.6)
2
Sort by Confidence
Arrange remaining detections in descending order of confidence scores
3
Pick Best Detection
Select the detection with highest confidence and mark it as "kept"
4
Suppress Overlaps
Calculate IoU with remaining detections and suppress those with IoU > threshold
5
Repeat
Continue with remaining detections until all are processed

4. Threshold Impact

0.3

Aggressive

High suppression
Fewer duplicates
Risk missing objects

0.5

Standard

Balanced approach
PASCAL VOC default
Good for most cases

0.7

Permissive

Low suppression
More duplicates
Higher recall

Trade-off: Lower IoU threshold = more aggressive suppression = fewer false positives but risk of missing nearby objects. Higher threshold = more permissive = better recall but more duplicates.

5. Multi-Class NMS

Important: NMS is applied separately for each object class. A person and a car can have high spatial overlap and both be kept, since they're different object types.
