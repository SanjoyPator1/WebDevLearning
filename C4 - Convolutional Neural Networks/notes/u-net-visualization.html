Explore the encoder path, bottleneck, decoder path, and skip connections to understand how U-Net processes images for semantic segmentation.

📉

Encoder Path

Progressively reduces spatial dimensions while increasing feature depth. Captures hierarchical features from low-level edges to high-level semantic concepts.

  • • Convolution + ReLU blocks
  • • Max pooling for downsampling
  • • Feature extraction and compression
🔗

Skip Connections

Bridge encoder and decoder layers at matching resolutions. Preserve fine-grained spatial information lost during compression.

  • • Direct feature copying
  • • Concatenation with decoder features
  • • Preserve spatial details
📈

Decoder Path

Progressively increases spatial dimensions using transpose convolutions. Combines upsampled features with skip connections for precise localization.

  • • Transpose convolution (upsampling)
  • • Feature concatenation
  • • Spatial reconstruction
🎯

Bottleneck

Lowest spatial resolution, highest feature depth. Captures the most abstract semantic representations of the input image.

  • • Maximum compression point
  • • Rich semantic features
  • • Minimal spatial information
🎨

Output Layer

1×1 convolution maps features to class probabilities. Each pixel gets a probability vector for all possible classes.

  • • Pixel-wise classification
  • • Class probability vectors
  • • Dense segmentation map
🏥

Applications

Originally designed for biomedical image segmentation, now used across many computer vision domains requiring precise pixel-level predictions.

  • • Medical image segmentation
  • • Autonomous driving
  • • Object detection boundaries

💡 Why Skip Connections Are Essential

❌ Without Skip Connections

Fine spatial details are lost during compression and cannot be recovered

Decoder only has access to heavily compressed semantic features

Results in blurry, imprecise segmentation boundaries

Poor localization accuracy for object boundaries

✅ With Skip Connections

High-resolution spatial information is preserved and directly passed to decoder

Decoder combines semantic context with fine-grained details

Produces sharp, accurate segmentation boundaries

Excellent pixel-wise classification accuracy

💻 U-Net Implementation Example 


def create_unet(input_shape, num_classes):
    """Complete U-Net implementation"""
    inputs = tf.keras.layers.Input(shape=input_shape)
    
    # Encoder path
    e1 = conv_block(inputs, 64)
    p1 = tf.keras.layers.MaxPooling2D(2)(e1)
    
    e2 = conv_block(p1, 128)
    p2 = tf.keras.layers.MaxPooling2D(2)(e2)
    
    e3 = conv_block(p2, 256)
    p3 = tf.keras.layers.MaxPooling2D(2)(e3)
    
    e4 = conv_block(p3, 512)
    p4 = tf.keras.layers.MaxPooling2D(2)(e4)
    
    # Bottleneck
    bottleneck = conv_block(p4, 1024)
    
    # Decoder path with skip connections
    d4 = decoder_block(bottleneck, e4, 512)  # Skip connection from e4
    d3 = decoder_block(d4, e3, 256)          # Skip connection from e3
    d2 = decoder_block(d3, e2, 128)          # Skip connection from e2
    d1 = decoder_block(d2, e1, 64)           # Skip connection from e1
    
    # Output layer
    outputs = tf.keras.layers.Conv2D(num_classes, 1, activation='softmax')(d1)
    
    return tf.keras.Model(inputs, outputs, name="U-Net")

def decoder_block(inputs, skip_features, num_filters):
    """Decoder block with skip connection"""
    # Upsample
    x = tf.keras.layers.Conv2DTranspose(num_filters, 2, strides=2, padding='same')(inputs)
    
    # Concatenate with skip connection
    x = tf.keras.layers.Concatenate()([x, skip_features])
    
    # Process combined features
    x = conv_block(x, num_filters)
    
    return x
