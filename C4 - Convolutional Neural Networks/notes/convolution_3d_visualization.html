🔑 Key Concepts

  • 3D Convolution: Filter depth must match input channels (3)
  • 27 Operations: Each output pixel requires 3×3×3 = 27 multiplications
  • Single Output: All channels sum to create one feature map
  • Multiple Filters: Different filters detect different patterns
  • Volume Output: n filters create n feature maps → n-channel output
  • Parallel Processing: Same input processed by multiple filters simultaneously
