3. Coordinate System Encoding

(0,0)
(1,1)

Coordinate Encoding Rules:

  • bx, by: Center position relative to grid cell [0,1]
  • bh, bw: Dimensions relative to entire image [0,∞)
  • Grid cell: (0,0) at top-left, (1,1) at bottom-right
  • Assignment: Object belongs to cell containing its center
Example:
Object center at 40% across, 30% down in cell
→ bx = 0.4, by = 0.3
Box width = 50% of image → bw = 0.5
