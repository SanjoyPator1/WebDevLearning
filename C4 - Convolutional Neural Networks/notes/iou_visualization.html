📊 Intersection over Union (IoU)

Interactive visualization for understanding object detection evaluation

1. What is IoU?

IoU = Intersection ÷ Union = |A ∩ B| ÷ |A ∪ B|
A: Ground Truth Box
The "correct" bounding box
B: Predicted Box
What your algorithm detected
A ∩ B: Intersection
Overlapping area
A ∪ B: Union
Total area covered
Key Insight: IoU measures how well two bounding boxes overlap.A score of 1.0 means perfect overlap, while 0.0 means no overlap at all.

3. Common IoU Scenarios

Perfect Match

IoU = 1.0

Identical boxes - best possible score

Good Detection

IoU = 0.6

Above standard threshold (0.5)

Threshold Case

IoU = 0.5

Exactly at standard threshold

Poor Detection

IoU = 0.2

Below threshold - considered wrong

No Overlap

IoU = 0.0

Completely missed detection

Size Mismatch

IoU = 0.36

Right location, wrong size

4. IoU Threshold Standards

≥ 0.9

Excellent

Near-perfect alignment

≥ 0.7

Very Good

High-quality detection

≥ 0.5

Standard

PASCAL VOC threshold

≥ 0.3

Poor

Usually considered wrong

< 0.3

Very Poor

Definitely wrong

Domain-Specific Thresholds: Medical imaging often uses IoU ≥ 0.7, while autonomous driving may require IoU ≥ 0.8 for safety-critical applications.
