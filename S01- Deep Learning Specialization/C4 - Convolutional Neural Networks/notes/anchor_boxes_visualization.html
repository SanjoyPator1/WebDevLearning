⚓ Anchor Boxes

Interactive visualization for multiple object detection per grid cell

1. The Multi-Object Problem

Problem: YOLO v1 can only detect one object per grid cell. What happens when multiple objects have their centers in the same cell?

Solution: Anchor boxes allow multiple predictions per cell, each specialized for different object shapes.

4. Before vs After Anchor Boxes

❌ Without Anchor Boxes
YOLO v1 Limitation
  • One object per grid cell
  • Single 8D output vector
  • Network confusion with multiple objects
  • Must choose between overlapping objects
  • Limited shape specialization
✅ With Anchor Boxes
YOLO v2+ Enhancement
  • Multiple objects per grid cell
  • Multiple 8D output vectors
  • Shape-specialized detection
  • Handles object overlap
  • Better recall and accuracy

5. Output Vector Structure

Without Anchor Boxes (YOLO v1):

Y = [Pc, bx, by, bh, bw, c1, c2, c3] // 8 dimensions Output: 3×3×8

With 2 Anchor Boxes (YOLO v2):

Y = [ // Anchor Box 1 Pc1, bx1, by1, bh1, bw1, c11, c21, c31, // Anchor Box 2 Pc2, bx2, by2, bh2, bw2, c12, c22, c32 ] // 16 dimensions Output: 3×3×16

6. Key Insights

📐 Shape Specialization
Different anchor shapes enable detection of objects with different aspect ratios - tall people, wide cars, square signs.
🎯 IoU Assignment
Objects are assigned to anchors based on shape similarity (IoU), ensuring optimal training targets.
⚡ Multiple Detection
Each grid cell can now detect multiple objects simultaneously without confusion.
📊 Better Performance
Improved recall and accuracy, especially for datasets with diverse object shapes.
