🏗️ YOLO Network Architecture

📸 Input Layer

448×448×3

RGB Image
↓

🧠 Convolutional Backbone

24 Conv Layers

Feature Extraction: 448×448×3 → 7×7×1024
↓

🔗 Fully Connected

2 FC Layers

4096 neurons → Final predictions
↓

📊 Output Layer

7×7×30

Grid predictions (2 anchors × 5 + 20 classes)

🔧 Architecture Details

  • 24 Conv layers + 2 FC layers
  • Inspired by GoogLeNet with 1×1 convolutions
  • Leaky ReLU activation (α=0.1)
  • Dropout (0.5) for regularization
  • ~50M parameters total

⚡ Key Features

  • Single forward pass - no proposals
  • Global features from entire image
  • Direct prediction of coordinates
  • End-to-end training with unified loss
  • Real-time inference (~22ms per image)

🧹 Non-Maximum Suppression & IoU

📏 Intersection over Union (IoU)

IoU measures the overlap between predicted and ground truth bounding boxes:

IoU = Area of Intersection / Area of Union
• IoU ≥ 0.5: Good detection
• IoU ≥ 0.7: Very good detection
• IoU = 1.0: Perfect match
