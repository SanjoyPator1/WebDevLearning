We want to find matrix $R$ such that:

**Translation**: "English vectors × Transformation matrix ≈ French vectors"

## The Learning Process: Optimization

### The Loss Function

We need to measure how good our transformation is. Enter the **Frobenius Norm**!

$$\text{Loss} = ||XR - Y||_F^2$$

**In plain English**: "How far apart are our predicted French vectors from the actual French vectors?"

---

## Deep Dive: Understanding the Frobenius Norm

### What is the Frobenius Norm?

The Frobenius norm is like measuring the "total distance" between two matrices. Think of it as the matrix version of the distance formula you learned in geometry.

**For a vector**: Distance = $\sqrt{(x_1-y_1)^2 + (x_2-y_2)^2}$

**For a matrix**: Frobenius norm = $\sqrt{\text{sum of all squared differences}}$

### Step-by-Step Example

Let's say our transformation gives us this difference matrix:

$$
A = XR - Y = \begin{bmatrix}
2 & 2 \\
2 & 2
\end{bmatrix}
$$

**Step 1**: Square each element

$$
A^2 = \begin{bmatrix}
2^2 & 2^2 \\
2^2 & 2^2
\end{bmatrix} = \begin{bmatrix}
4 & 4 \\
4 & 4
\end{bmatrix}
$$

**Step 2**: Sum all elements
$$\text{Sum} = 4 + 4 + 4 + 4 = 16$$

**Step 3**: Take the square root
$$||A||_F = \sqrt{16} = 4$$

### General Formula

$$||A||_F = \sqrt{\sum_{i=1}^{m} \sum_{j=1}^{n} |a_{ij}|^2}$$

### Python Implementation

```python
import numpy as np

# Example matrix A
A = np.array([[2, 2],
              [2, 2]])

# Method 1: Manual calculation
frobenius_norm = np.sqrt(np.sum(A**2))
print(f"Frobenius norm: {frobenius_norm}")  # Output: 4.0

# Method 2: Using NumPy
frobenius_norm_np = np.linalg.norm(A, 'fro')
print(f"Frobenius norm (NumPy): {frobenius_norm_np}")  # Output: 4.0
```

### Why Use Squared Frobenius Norm?

Instead of minimizing $||XR - Y||_F$, we minimize $||XR - Y||_F^2$

**Reasons**:

1. **Easier derivatives**: No square root to deal with

2. **Same optimal solution**: Minimizing $f(x)$ is same as minimizing $f(x)^2$ when $f(x) \geq 0$

   **Example to understand this**:

   Let's say we want to minimize $f(x) = (x - 3)^2$ vs $g(x) = ((x - 3)^2)^2 = (x - 3)^4$

   - $f(x) = (x - 3)^2$ reaches minimum when $x = 3$ (minimum value = 0)
   - $g(x) = (x - 3)^4$ also reaches minimum when $x = 3$ (minimum value = 0)

   **Why this works**: When $f(x) \geq 0$ (which is true for norms), the function $f(x)^2$ has the same minimum point as $f(x)$ because:

   - If $f(a) < f(b)$, then $f(a)^2 < f(b)^2$ (since both are positive)
   - The ordering of function values is preserved when squaring positive numbers

   **Visual intuition**:

   ```
   f(x) = |x|:     \  /     minimum at x = 0
   f(x)² = x²:     \  /     minimum at x = 0 (same location!)
   ```

3. **Computational efficiency**: Avoid expensive square root operations

## Gradient Derivation: The Mathematical Heart

> **Note:** It's better to do this math derivation and the example in a notebook for better clarity and understanding.

### The Loss Function (Squared Frobenius Norm)

$$\mathcal{L}(R) = ||XR - Y||_F^2$$

### Expanding the Norm

To understand how we get from the Frobenius norm to the trace formula, let's break this down step by step.

**First, what is the trace?**

The **trace** of a matrix is simply the sum of its diagonal elements:

$\text{tr}(A) = \sum_{i=1}^{n} a_{ii} = a_{11} + a_{22} + \cdots + a_{nn}$

**Example**:
$A = \begin{bmatrix} 3 & 7 & 2 \\ 1 & 4 & 9 \\ 5 & 6 & 8 \end{bmatrix} \Rightarrow \text{tr}(A) = 3 + 4 + 8 = 15$

**Now, how do we get from Frobenius norm to trace?**

The key insight is this fundamental relationship:
$||A||_F^2 = \text{tr}(A^T A)$

**Step-by-step derivation**:

**Step 1**: Start with the definition of Frobenius norm
$||A||_F^2 = \sum_{i=1}^{m} \sum_{j=1}^{n} |a_{ij}|^2$

**Step 2**: Understand what $A^T A$ looks like
If $A$ is $m \times n$, then $A^T A$ is $n \times n$, and its diagonal elements are:
$(A^T A)_{jj} = \sum_{i=1}^{m} a_{ij}^2$

**Step 3**: Connect the dots
$\text{tr}(A^T A) = \sum_{j=1}^{n} (A^T A)_{jj} = \sum_{j=1}^{n} \sum_{i=1}^{m} a_{ij}^2 = \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}^2 = ||A||_F^2$

**Concrete example**:
$A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$

**Method 1 (Direct Frobenius)**:
$||A||_F^2 = 1^2 + 2^2 + 3^2 + 4^2 = 1 + 4 + 9 + 16 = 30$

**Method 2 (Using trace)**:
$A^T A = \begin{bmatrix} 1 & 3 \\ 2 & 4 \end{bmatrix} \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix} = \begin{bmatrix} 10 & 14 \\ 14 & 20 \end{bmatrix}$

$\text{tr}(A^T A) = 10 + 20 = 30$ ✓

**Therefore**: $||XR - Y||_F^2 = \text{tr}((XR - Y)^T(XR - Y))$

### Step-by-Step Derivation

**Step 1**: Expand the expression
$$\mathcal{L}(R) = \text{tr}((XR)^T(XR) - (XR)^T Y - Y^T(XR) + Y^T Y)$$

**Step 2**: Use trace properties

**Key trace properties we need**:

1. **Linearity**: $\text{tr}(A + B) = \text{tr}(A) + \text{tr}(B)$
2. **Scalar multiplication**: $\text{tr}(cA) = c \cdot \text{tr}(A)$
3. **Cyclic property**: $\text{tr}(ABC) = \text{tr}(CAB) = \text{tr}(BCA)$

**Step-by-step expansion**:

Starting from: $\text{tr}((XR - Y)^T(XR - Y))$

**Expand the product**:
$(XR - Y)^T(XR - Y) = (XR)^T(XR) - (XR)^T Y - Y^T(XR) + Y^T Y$

**Apply linearity of trace**:
$\mathcal{L}(R) = \text{tr}((XR)^T(XR)) - \text{tr}((XR)^T Y) - \text{tr}(Y^T(XR)) + \text{tr}(Y^T Y)$

**Use the fact that** $\text{tr}(A^T B) = \text{tr}(B^T A)$ **and** $\text{tr}(A) = \text{tr}(A^T)$:

- $\text{tr}((XR)^T Y) = \text{tr}(Y^T XR)$
- $\text{tr}(Y^T(XR)) = \text{tr}(Y^T XR)$

So: $\text{tr}((XR)^T Y) = \text{tr}(Y^T(XR))$

**Combine like terms**:
$\mathcal{L}(R) = \text{tr}(R^T X^T X R) - 2\text{tr}(Y^T X R) + \text{tr}(Y^T Y)$

**Note**:

- $(XR)^T(XR) = R^T X^T X R$ (using $(AB)^T = B^T A^T$)
- $\text{tr}(Y^T Y)$ is constant (doesn't depend on $R$)

**Step 3**: Take the derivative with respect to $R$

**Matrix calculus rules we need**:

1. **Linear term**: $\frac{\partial}{\partial R} \text{tr}(B^T R) = B$
2. **Quadratic term**: $\frac{\partial}{\partial R} \text{tr}(R^T A R) = 2AR$ (when $A$ is symmetric)

**Detailed derivation of the quadratic term rule**:

For $\frac{\partial}{\partial R} \text{tr}(R^T A R)$ where $A$ is symmetric:

Let $f(R) = \text{tr}(R^T A R)$. Using the definition of matrix derivatives:

$\frac{\partial f}{\partial R_{ij}} = \frac{\partial}{\partial R_{ij}} \sum_{k,l} R_{kl} A_{kl} R_{kl}$

This involves partial derivatives of each element. The full derivation is complex, but the result is:

$\frac{\partial}{\partial R} \text{tr}(R^T A R) = AR + A^T R$

When $A$ is symmetric ($A = A^T$):
$\frac{\partial}{\partial R} \text{tr}(R^T A R) = AR + AR = 2AR$

**Applying the rules to our terms**:

1. $\frac{\partial}{\partial R} \text{tr}(R^T X^T X R) = 2(X^T X)R$

   - Here $A = X^T X$, which is symmetric since $(X^T X)^T = X^T X$

2. $\frac{\partial}{\partial R} \text{tr}(Y^T X R) = X^T Y$

   - Here $B^T = Y^T X$, so $B = X^T Y$

3. $\frac{\partial}{\partial R} \text{tr}(Y^T Y) = 0$ (constant term)

**Combining everything**:
$\frac{\partial \mathcal{L}}{\partial R} = 2(X^T X)R - 2(X^T Y) = 2X^T(XR - Y)$

**Step 4**: Factor out the 2
$$\nabla_R \mathcal{L} = 2X^T(XR - Y)$$

### Scaling by Training Size

For numerical stability, we divide by the number of training examples $m$:

$$\nabla_R \mathcal{L} = \frac{2}{m} X^T(XR - Y)$$

## Numerical Example: Complete Walkthrough

### Setup

Let's work with a simple 2×2 example:

$$X = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad Y = \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix}, \quad R = \begin{bmatrix} 1.5 & 0.5 \\ 0.5 & 1.5 \end{bmatrix}$$

### Step 1: Calculate $XR$

$$XR = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} 1.5 & 0.5 \\ 0.5 & 1.5 \end{bmatrix} = \begin{bmatrix} 1.5 & 0.5 \\ 0.5 & 1.5 \end{bmatrix}$$

### Step 2: Calculate $XR - Y$

$$XR - Y = \begin{bmatrix} 1.5 & 0.5 \\ 0.5 & 1.5 \end{bmatrix} - \begin{bmatrix} 2 & 1 \\ 1 & 2 \end{bmatrix} = \begin{bmatrix} -0.5 & -0.5 \\ -0.5 & -0.5 \end{bmatrix}$$

### Step 3: Calculate Loss (Squared Frobenius Norm)

$$\text{Loss} = ||XR - Y||_F^2 = (-0.5)^2 + (-0.5)^2 + (-0.5)^2 + (-0.5)^2 = 1.0$$

### Step 4: Calculate Gradient

$$\nabla_R \mathcal{L} = \frac{2}{m} X^T(XR - Y)$$

With $m = 2$ (two training examples):

$$X^T = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}$$

$$\nabla_R \mathcal{L} = \frac{2}{2} \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} \begin{bmatrix} -0.5 & -0.5 \\ -0.5 & -0.5 \end{bmatrix} = \begin{bmatrix} -0.5 & -0.5 \\ -0.5 & -0.5 \end{bmatrix}$$

### Step 5: Update $R$

With learning rate $\alpha = 0.1$:

$$R_{new} = R_{old} - \alpha \cdot \nabla_R \mathcal{L}$$

$$R_{new} = \begin{bmatrix} 1.5 & 0.5 \\ 0.5 & 1.5 \end{bmatrix} - 0.1 \begin{bmatrix} -0.5 & -0.5 \\ -0.5 & -0.5 \end{bmatrix}$$

$$R_{new} = \begin{bmatrix} 1.55 & 0.55 \\ 0.55 & 1.55 \end{bmatrix}$$

## The Complete Implementation

```python
import numpy as np

def transform_word_vectors(X, Y, learning_rate=0.01, num_iterations=1000):
    """
    Complete implementation of word vector transformation learning

    Args:
        X: English word vectors (m x d)
        Y: French word vectors (m x d)
        learning_rate: Step size for gradient descent
        num_iterations: Number of training iterations

    Returns:
        R: Learned transformation matrix (d x d)
        losses: List of loss values during training
    """
    m, d = X.shape

    # Initialize transformation matrix randomly
    R = np.random.normal(0, 0.1, size=(d, d))
    losses = []

    for i in range(num_iterations):
        # Forward pass: calculate predicted Y
        Y_pred = X @ R

        # Calculate loss (squared Frobenius norm)
        diff = Y_pred - Y
        loss = np.sum(diff**2) / m  # Mean squared error version
        losses.append(loss)

        # Calculate gradient
        gradient = (2/m) * X.T @ diff

        # Update R
        R = R - learning_rate * gradient

        # Print progress
        if i % 100 == 0:
            print(f"Iteration {i:4d}, Loss: {loss:.6f}")

    return R, losses

# Example usage
def test_transformation():
    # Create sample data
    np.random.seed(42)
    m, d = 100, 50  # 100 word pairs, 50-dimensional vectors

    # Generate synthetic English vectors
    X = np.random.normal(0, 1, size=(m, d))

    # Create a true transformation matrix
    true_R = np.random.normal(0, 0.1, size=(d, d))

    # Generate corresponding French vectors
    Y = X @ true_R + np.random.normal(0, 0.01, size=(m, d))  # Add small noise

    # Learn the transformation
    learned_R, losses = transform_word_vectors(X, Y, learning_rate=0.01, num_iterations=1000)

    # Test the learned transformation
    Y_predicted = X @ learned_R
    final_error = np.linalg.norm(Y_predicted - Y, 'fro') / np.linalg.norm(Y, 'fro')

    print(f"\nFinal relative error: {final_error:.6f}")
    print(f"Final loss: {losses[-1]:.6f}")

    return learned_R, losses
```

## K-NN Algorithm: The Formal Definition

### What is K-Nearest Neighbors?

**Definition**: Given a query point, find the **K closest points** in your dataset based on some distance metric.

### The Algorithm Steps

```python
def k_nearest_neighbors(query_vector, dataset, k=5):
    """
    Find K nearest neighbors to query_vector in dataset

    Args:
        query_vector: The point we want to find neighbors for
        dataset: Collection of all possible neighbors
        k: Number of neighbors to return

    Returns:
        List of k closest neighbors with their distances
    """
    distances = []

    # Step 1: Calculate distance to every point in dataset
    for i, data_point in enumerate(dataset):
        distance = calculate_distance(query_vector, data_point)
        distances.append((i, data_point, distance))

    # Step 2: Sort by distance (ascending)
    distances.sort(key=lambda x: x[2])

    # Step 3: Return top K closest
    return distances[:k]
```

### Distance Metrics

**Common distance measures**:

1. **Euclidean Distance**: $d = \sqrt{\sum_{i=1}^{n} (x_i - y_i)^2}$
2. **Cosine Similarity**: $\text{sim} = \frac{\mathbf{a} \cdot \mathbf{b}}{||\mathbf{a}|| \cdot ||\mathbf{b}||}$
3. **Manhattan Distance**: $d = \sum_{i=1}^{n} |x_i - y_i|$

**For word vectors**: Cosine similarity is typically preferred because it measures **semantic similarity** rather than magnitude.

```python
    """Calculate cosine similarity between vectors a and b"""
    dot_product = np.dot(a, b)
    magnitude_a = np.linalg.norm(a)
```

## Building a Hash Table: Complete Implementation

### Python Implementation

```python
def create_basic_hash_table(value_list, n_buckets):
    """
    Create a hash table using modulo hash function

    Args:
        value_list: List of values to hash
        n_buckets: Number of buckets in hash table

    Returns:
        hash_table: Dictionary with bucket_id as key, list of values as value
    """

    # Step 1: Define the hash function
    def hash_function(value):
        return value % n_buckets

    # Step 2: Initialize hash table with empty buckets
    # Dictionary comprehension: {0: [], 1: [], 2: [], ...}
    hash_table = {i: [] for i in range(n_buckets)}

    # Step 3: Hash each value and add to appropriate bucket
    for value in value_list:
        # Calculate which bucket this value belongs to
        hash_value = hash_function(value)

        # Add the value to that bucket
        hash_table[hash_value].append(value)

    return hash_table

# Example usage
vectors = [100, 14, 17, 10, 97]
hash_table = create_basic_hash_table(vectors, 10)

print("Hash Table:")
for bucket_id, values in hash_table.items():
    if values:  # Only print non-empty buckets
        print(f"Bucket {bucket_id}: {values}")
```

```
Bucket 4: [14]
Bucket 7: [17, 97]
```

## Key Terminology Summary

### Hash Function 📊

**Definition**: A function that maps data to a fixed-size bucket identifier

**Example**: `hash(vector) = vector % 10`

**Purpose**: Determine which bucket an item belongs to

### Hash Value/Hash 🏷️

**Definition**: The output of a hash function; the bucket identifier

**Example**: For vector 14, hash value = 4

**Purpose**: Acts as the "address" for storage

### Hash Table 🗂️

**Definition**: The entire data structure containing all buckets

**Example**: `{0: [100, 10], 1: [], 2: [], ..., 7: [17, 97]}`

**Purpose**: Organized storage system for efficient retrieval

### Bucket 🪣

**Definition**: Individual storage container within hash table

**Example**: Bucket 0 contains [100, 10]

**Purpose**: Groups items with same hash value

### Hash Collision 💥

**Definition**: When different inputs produce the same hash value

**Example**: Both 10 and 100 hash to bucket 0

**Purpose**: Natural behavior; handled by bucket storage

# 5. Locality Sensitive Hashing

## The Revolutionary Idea: Location-Aware Hashing

Remember our problem from the previous section? Basic hash functions scattered similar items randomly across buckets. **Locality Sensitive Hashing (LSH)** solves this by creating a hash function that **cares about location**!

**Core Principle**:

> Similar vectors should have a **high probability** of being hashed to the **same bucket**.

Let's break this down:

- **Locality** = Location/Neighborhood in vector space
- **Sensitive** = Responsive to/Caring about
- **Hashing** = Organizing into buckets

**LSH** = A hashing method that groups vectors based on their **geometric proximity**!

## The Dot Product: The Secret to Determining Sides

### Why Use Dot Product?

The **dot product** between a vector and the normal vector tells us **which side of the plane** the vector is on!

- **Negative (-)**: Vector is on the opposite side
- **Zero (0)**: Vector lies exactly on the plane

## The Intuition Behind Dot Product: Detailed Explanation

### Why Does This Work?

The dot product measures **how much two vectors point in the same direction**:

**Geometric Interpretation**:

$$\mathbf{P} \cdot \mathbf{V} = ||\mathbf{P}|| \cdot ||\mathbf{V}|| \cdot \cos(\theta)$$

Where $\theta$ is the angle between vectors P and V.

**Key Insight**: The sign of $\cos(\theta)$ tells us about the angle:

- **θ < 90°**: $\cos(\theta) > 0$ → **Positive dot product** → Same general direction
- **θ = 90°**: $\cos(\theta) = 0$ → **Zero dot product** → Perpendicular
- **θ > 90°**: $\cos(\theta) < 0$ → **Negative dot product** → Opposite directions

### Understanding Through Projection

**The Gravity Analogy**:

1. **Imagine vector P as Earth's surface**
2. **You're standing at the tip of vector V**
3. **Drop a rock with gravity** - it falls perpendicular to P
4. **The shadow of V on P** is the projection
5. **Length of shadow** = dot product magnitude
6. **Direction of shadow** = dot product sign

```bash
        ↗

     /
----+--------  P (Earth's surface)
    ↑
```

```python
    """
    Determine which side of a plane a vector is on

    Args:
```

## LSH Hash Function: Putting It All Together

### Creating the LSH Hash Function

Now that we understand how to classify vectors relative to a plane, we can create our LSH hash function:

```python
def lsh_hash_function(vectors, normal_vector):
    """
    LSH hash function using a single plane

    Args:
        vectors: List of vectors to hash
        normal_vector: Normal vector defining the plane

    Returns:
        hash_table: Dictionary with buckets 0 and 1
    """
    # Initialize hash table with 2 buckets (positive and negative sides)
    hash_table = {0: [], 1: []}  # 0 = negative side, 1 = positive side

    for vector in vectors:
        # Calculate which side of plane
        dot_product = np.dot(normal_vector, vector)

        # Assign to bucket based on sign
        if dot_product >= 0:
            bucket = 1  # Positive side (including on-plane)
        else:
            bucket = 0  # Negative side

        hash_table[bucket].append(vector.tolist())

    return hash_table

# Example usage
vectors = [
    np.array([1, 2]),    # Should go to bucket 1 (positive)
    np.array([-1, 1]),   # Should go to bucket 1 (zero, but we assign to positive)
    np.array([-2, -1]),  # Should go to bucket 0 (negative)
    np.array([2, 3]),    # Should go to bucket 1 (positive)
    np.array([-3, -2])   # Should go to bucket 0 (negative)
]

P = np.array([1, 1])
result = lsh_hash_function(vectors, P)

print("LSH Hash Table:")
for bucket_id, bucket_vectors in result.items():
    print(f"Bucket {bucket_id}: {bucket_vectors}")
```

**Output**:

## The Multiple Plane Process

### Step-by-Step Algorithm

**Goal**: Convert multiple plane responses into a single hash value

**Process**:

1. **Test each plane**: Get positive (+) or negative (-) response by computing dot product
2. **Convert to binary**: Positive → 1, Negative → 0
3. **Combine into hash**: Use binary-to-decimal conversion

### Example from the Lecture

Let's work through the specific example from the lecture image:

**Given**:

- **Vector v**: Some test vector
- **Three planes**: P₁, P₂, P₃ (represented by their normal vectors)

**Step 1: Calculate Dot Products with Each Plane**

**Plane 1**: $\mathbf{P_1} \cdot \mathbf{v}^T = 3$

- Result: **Positive** → $h_1 = 1$

**Plane 2**: $\mathbf{P_2} \cdot \mathbf{v}^T = 5$

- Result: **Positive** → $h_2 = 1$

**Plane 3**: $\mathbf{P_3} \cdot \mathbf{v}^T = -2$

- Result: **Negative** → $h_3 = 0$

**Step 2: Combine Using Binary Formula**

$$\text{hash} = 2^0 \times h_1 + 2^1 \times h_2 + 2^2 \times h_3$$

$$= 1 \times 1 + 2 \times 1 + 4 \times 0$$

$$= 1 + 2 + 0 = 3$$

**Final Result**: Hash value = **3**

## Understanding the Binary Encoding

### Why Powers of 2?

The formula $2^0 \times h_1 + 2^1 \times h_2 + 2^2 \times h_3$ is actually **binary-to-decimal conversion**!

**Binary Representation**:

- $h_1 = 1$ (rightmost bit)
- $h_2 = 1$ (middle bit)
- $h_3 = 0$ (leftmost bit)

**Binary String**: `011` (reading right to left: $h_3 h_2 h_1$)

**Decimal Conversion**: `011₂ = 0×4 + 1×2 + 1×1 = 3₁₀`

### Visual Binary Representation

```bash
Plane Responses:  h₃  h₂  h₁
                   0   1   1
                   ↓   ↓   ↓
Powers of 2:      2²  2¹  2⁰
                   4   2   1
                   ↓   ↓   ↓
Contribution:    0×4 1×2 1×1 = 0 + 2 + 1 = 3
```

**The pattern**: Each plane contributes a **binary digit** to the final hash value!

## The General Formula

### Mathematical Expression

For **H planes** and a vector **v**:

$$\text{hash\_value} = \sum_{i=0}^{H-1} 2^i \times h_i$$

Where:

- $h_i \in \{0, 1\}$ is the binary response from plane $i$
- $H$ is the total number of planes
- $i$ is the plane index (starting from 0)

### The Hash Function Rules

**Rule 1**:
$$\text{If } \mathbf{P_i} \cdot \mathbf{v} \geq 0 \text{ then } h_i = 1$$

**Rule 2**:
$$\text{If } \mathbf{P_i} \cdot \mathbf{v} < 0 \text{ then } h_i = 0$$

**Rule 3**:
$$\text{hash\_value} = \sum_{i=0}^{H-1} 2^i \times h_i$$

### Interpretation

**Each plane contributes**:

- **Plane 0**: Weight $2^0 = 1$ (contributes 0 or 1)
- **Plane 1**: Weight $2^1 = 2$ (contributes 0 or 2)
- **Plane 2**: Weight $2^2 = 4$ (contributes 0 or 4)
- **Plane i**: Weight $2^i$ (contributes 0 or $2^i$)

**Total possible hash values**: $0$ to $2^H - 1$

```python
import numpy as np

def multi_plane_hash(vector, planes):
    """
    Calculate hash value using multiple planes

    Args:
        vector: Input vector to hash (numpy array)
        planes: List of planes (represented by their normal vectors) (list of numpy arrays)

    Returns:
        hash_value: Integer hash value (0 to 2^len(planes) - 1)
    """
    hash_value = 0

    for i, plane in enumerate(planes):
        # Calculate dot product between vector and plane
        dot_product = np.dot(plane, vector)

        # Convert to binary (1 if positive/zero, 0 if negative)
        if dot_product >= 0:
            h_i = 1
        else:
            h_i = 0

        # Add contribution: 2^i * h_i
        hash_value += (2 ** i) * h_i

    return hash_value

# Example usage with our vectors

    np.array([1, 0]),  # P1: vertical plane
    np.array([0, 1]),  # P2: horizontal plane
```

## Understanding Hash Collisions in Multiple Planes

### When Do Vectors Get the Same Hash?

Two vectors get the **same hash value** when they fall on the **same side** of **all planes**.

**Example**: Vectors in the same "octant" (3D) or "quadrant" (2D) relative to all planes.

### Example of Hash Collision

**Vector D**: $\mathbf{v_D} = (1, 1)$

**Vector E**: $\mathbf{v_E} = (3, 2)$

Both vectors are in the **top-right region**:

**For both vectors**:

- **Plane 1** (vertical): Positive → $h_1 = 1$
- **Plane 2** (horizontal): Positive → $h_2 = 1$
- **Plane 3** (diagonal): Positive → $h_3 = 1$

**Result**: Both get **hash = 7** → **Hash collision**

**This is good!** Similar vectors (both in top-right) get the same hash value, which is exactly what we want for LSH!

## Why This Creates Locality Sensitivity

### The Key Insight

**Locality-sensitive property**: Vectors that are **geometrically close** are likely to:

1. **Fall on the same side** of most planes
2. **Have similar binary patterns**
3. **Get the same or nearby hash values**

### Geometric Intuition

Think of each plane as asking a **yes/no question** about the vector:

- **Plane P₁(1,0)**: "Is the x-coordinate positive?"
- **Plane P₂(0,1)**: "Is the y-coordinate positive?"
- **Plane P₃(1,1)**: "Is x+y positive?"

**Similar vectors** will answer these questions **similarly**, leading to **similar hash values**!

## Why This Works: The Mathematics of Probability

### Single Hash Table Probability

**Probability that two similar vectors end up in same bucket**:

- With 3 planes: ~60-70% chance
- **Problem**: 30-40% chance of missing similar vectors!

### Multiple Hash Tables Probability

**Probability that two similar vectors end up together in AT LEAST ONE table**:

- With 1 table: 70% chance
- With 2 tables: 91% chance
- With 3 tables: 97% chance
- With 5 tables: 99.8% chance

**Mathematical formula**:
$$P(\text{found in at least one table}) = 1 - (1 - p)^L$$

Where:

- $p$ = probability of being in same bucket in one table
- $L$ = number of hash tables

## The Algorithm: Approximate Nearest Neighbors

### Complete ANN Algorithm

```python
import numpy as np
from collections import defaultdict

def create_multiple_hash_tables(vectors, num_tables=5, num_planes=10):
    """
    Create multiple hash tables using different random plane sets

    Args:
        vectors: List of vectors to hash
        num_tables: Number of different hash tables to create
        num_planes: Number of planes per hash table

    Returns:
        hash_tables: List of hash tables
        plane_sets: List of plane sets used for each table
    """
    d = len(vectors[0])  # Vector dimension
    hash_tables = []
    plane_sets = []

    for table_idx in range(num_tables):
        # Create random planes for this table
        planes = np.random.normal(0, 1, (num_planes, d))
        plane_sets.append(planes)

        # Create hash table for this set of planes
        hash_table = defaultdict(list)

        for i, vector in enumerate(vectors):
            # Calculate hash value for this vector
            hash_val = compute_hash(vector, planes)
            hash_table[hash_val].append(i)  # Store vector index

        hash_tables.append(hash_table)

    return hash_tables, plane_sets

def compute_hash(vector, planes):
    """Compute hash value using multiple planes"""
    hash_val = 0
    for i, plane in enumerate(planes):
        dot_product = np.dot(plane, vector)
        if dot_product >= 0:
            hash_val += 2**i
    return hash_val

def approximate_nearest_neighbors(query_vector, vectors, hash_tables, plane_sets, k=5):
    """
    Find approximate nearest neighbors using multiple hash tables
    """
    candidate_indices = set()

    # Search in each hash table
    for hash_table, planes in zip(hash_tables, plane_sets):
        # Get hash value for query in this table
        query_hash = compute_hash(query_vector, planes)

        # Get all vectors in the same bucket
        if query_hash in hash_table:
            candidate_indices.update(hash_table[query_hash])

    # Calculate actual distances to candidates
    candidates_with_distances = []
    for idx in candidate_indices:
        distance = np.linalg.norm(vectors[idx] - query_vector)
        candidates_with_distances.append((idx, distance))

    # Sort by distance and return top k
    candidates_with_distances.sort(key=lambda x: x[1])
    return candidates_with_distances[:k]

# Example usage
def example_ann_search():
    # Create sample 2D vectors (in practice, these would be high-dimensional)
    vectors = [
        np.array([2, 3]),    # Similar to query
        np.array([2.1, 2.9]), # Very similar to query
        np.array([-1, 2]),   # Somewhat similar
        np.array([-2, -1]),  # Different
        np.array([10, 10]),  # Very different
        np.array([1.9, 3.1]) # Similar to query
    ]

    query = np.array([2, 3])

    # Create multiple hash tables
    hash_tables, plane_sets = create_multiple_hash_tables(vectors, num_tables=3, num_planes=4)

    # Find approximate nearest neighbors
    results = approximate_nearest_neighbors(query, vectors, hash_tables, plane_sets, k=3)

    print("Approximate Nearest Neighbors:")
    for idx, distance in results:
        print(f"Vector {idx}: {vectors[idx]} (distance: {distance:.3f})")

# Run example
```

### 1. **Multi-Probe LSH**

Instead of just checking one bucket, check **nearby buckets** too:

```python
def multi_probe_search(query_hash, hash_table, num_probes=3):
    """Check nearby hash buckets for more candidates"""
    candidates = set()

    # Check exact hash
    if query_hash in hash_table:
        candidates.update(hash_table[query_hash])

    # Check nearby hashes (flip 1 bit, 2 bits, etc.)
    for num_flips in range(1, num_probes):
        for bit_positions in itertools.combinations(range(num_planes), num_flips):
            nearby_hash = query_hash
            for pos in bit_positions:
                nearby_hash ^= (1 << pos)  # Flip bit at position pos

            if nearby_hash in hash_table:
                candidates.update(hash_table[nearby_hash])

    return candidates
```

## Common Pitfalls and Solutions

### Pitfall 1: **Too Few Hash Tables**

**Problem**: Low recall (missing true neighbors)

**Solution**: Increase number of hash tables

### Pitfall 2: **Too Many Planes per Table**

**Problem**: Buckets become too small, many empty buckets

**Solution**: Reduce planes per table, increase number of tables

### Pitfall 3: **Imbalanced Hash Buckets**

**Problem**: Some buckets have too many vectors, others empty

**Solution**: Use better random seed, consider data-aware plane selection

### Pitfall 4: **Memory Explosion**

**Problem**: Too many hash tables consume too much memory

**Solution**: Balance number of tables vs. planes per table

## Implementation Tips

### Efficient Hash Computation

```python
def vectorized_multi_table_hash(vector, all_plane_sets):
    """
    Compute hashes for all tables simultaneously - much faster!
    """
    hashes = []
    for planes in all_plane_sets:
        # Vectorized dot product: (num_planes,) shaped result
        dot_products = np.dot(planes, vector)

        # Convert to binary: (num_planes,) boolean array
        bits = (dot_products >= 0)

        # Convert to hash value using powers of 2
        powers_of_2 = 2 ** np.arange(len(bits))
        hash_val = np.sum(bits * powers_of_2)

        hashes.append(hash_val)

    return hashes
```

## From Words to Documents: The Final Application

We've learned how to find similar **words** using vector representations and fast nearest neighbor search. Now let's scale up to the ultimate goal: **finding similar documents** in large text collections!

**The Challenge**: How do we represent entire documents (sentences, paragraphs, articles) as vectors that capture their meaning?

## The Core Idea: Documents as Vector Sums

### From Individual Words to Whole Documents

The simplest and most intuitive approach:

**Document Vector = Sum of all Word Vectors in the document**


**Mathematical Formula**:
$$\mathbf{doc\_vector} = \sum_{i=1}^{n} \mathbf{word\_vector}_i$$

Where $n$ is the number of words in the document.

## Complete Implementation

### Document Embedding Function

```python
def create_document_embedding(document, word_embeddings):
    """
    Convert a document to a vector by summing word vectors

    Args:
        document: String containing the document text
        word_embeddings: Dictionary mapping words to vectors

    Returns:
        document_vector: Numpy array representing the document
    """
    # Get the dimension of word vectors
    first_vector = next(iter(word_embeddings.values()))
    vector_dim = len(first_vector)

    # Initialize document embedding as zeros
    document_embedding = np.zeros(vector_dim)

    # Split document into words
    words = document.lower().split()  # Convert to lowercase for matching

    # Sum up word vectors
    for word in words:
        if word in word_embeddings:
            word_vector = word_embeddings[word]
            document_embedding += word_vector
        else:
            # Word not in dictionary, add zero vector (no contribution)
            print(f"Warning: '{word}' not found in word embeddings")

    return document_embedding
```

```python
def document_search_system(documents, word_embeddings, query, k=3):
    """
    Complete document search system using vector similarity

    Args:
        documents: List of document strings
        word_embeddings: Word embedding dictionary
        query: Query string to search for
        k: Number of similar documents to return

    Returns:
        results: List of (document, similarity_score) tuples
    """
    # Convert query to vector
    query_vector = create_document_embedding(query, word_embeddings)
    print(f"Query: '{query}'")
    print(f"Query vector: {query_vector}")
    print()

    # Convert all documents to vectors and calculate similarities
    similarities = []
    for doc in documents:

        # Calculate cosine similarity
        similarity = cosine_similarity(query_vector, doc_vector)
        similarities.append((doc, similarity, doc_vector))

    # Sort by similarity (descending)
    similarities.sort(key=lambda x: x[1], reverse=True)

    # Return top k results
    return similarities[:k]

def cosine_similarity(vec1, vec2):
    """Calculate cosine similarity between two vectors"""
    if np.linalg.norm(vec1) == 0 or np.linalg.norm(vec2) == 0:
        return 0
    return np.dot(vec1, vec2) / (np.linalg.norm(vec1) * np.linalg.norm(vec2))
```

#### 1. **Weighted Average (TF-IDF Weighting)**

```python
def create_tfidf_weighted_embedding(document, word_embeddings, tfidf_weights):
    """
    Create document embedding using TF-IDF weighted word vectors
    """
    document_embedding = np.zeros(len(next(iter(word_embeddings.values()))))
    words = document.lower().split()

    for word in words:
        if word in word_embeddings and word in tfidf_weights:
            weight = tfidf_weights[word]
            word_vector = word_embeddings[word]
            document_embedding += weight * word_vector

    return document_embedding
```

#### 2. **Remove Stop Words**

```python
def create_embedding_without_stopwords(document, word_embeddings):
    """
    Create document embedding excluding common stop words
    """
    stop_words = {'the', 'a', 'an', 'and', 'or', 'but', 'in', 'on', 'at', 'to', 'for', 'of', 'with', 'by', 'is', 'are', 'was', 'were'}

    document_embedding = np.zeros(len(next(iter(word_embeddings.values()))))
    words = [word for word in document.lower().split() if word not in stop_words]

    for word in words:
        if word in word_embeddings:
            document_embedding += word_embeddings[word]

    return document_embedding
```

#### 3. **Normalize by Document Length**

```python
def create_normalized_embedding(document, word_embeddings):
    """
    Create document embedding normalized by document length
    """
    document_embedding = create_document_embedding(document, word_embeddings)
    words = [word for word in document.lower().split() if word in word_embeddings]

    if len(words) > 0:
        document_embedding = document_embedding / len(words)

    return document_embedding
```
