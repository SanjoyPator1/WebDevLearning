**Mathematical formula:**

**⚠️ GOTCHA #5**: Numerical overflow!

### Milestone 3.2: Implement Gradient Descent

**What to implement**: Create `gradient_descent(X, y, theta, alpha, num_iters)` function

**Function signature:**

```python
def gradient_descent(X, y, theta, alpha, num_iters):
    """
    Train logistic regression using gradient descent

    Args:
        X: feature matrix (m, 3)
        y: labels (m, 1)
        theta: initial parameters (3, 1)
        alpha: learning rate (e.g., 1e-9)
        num_iters: number of iterations (e.g., 1500)

    Returns:
        J: final cost
        theta: trained parameters
    """
    pass  # Your implementation here
```

**Algorithm:**

```
For each iteration:
    1. Compute predictions: h = sigmoid(X @ theta)
    2. Compute gradient: grad = (1/m) * X.T @ (h - y)
    3. Update parameters: theta = theta - alpha * grad
    4. Compute cost: J = (-1/m) * (y.T @ log(h) + (1-y).T @ log(1-h))
```

**⚠️ GOTCHA #6**: Shape mismatches will haunt you!

- X is (m, 3)
- theta is (3, 1)
- y is (m, 1)
- h must be (m, 1)
- If shapes are wrong, you'll get broadcasting errors or wrong results

**⚠️ GOTCHA #7**: The learning rate trap!

- If alpha too large (e.g., 0.1) → cost explodes
- If alpha too small (e.g., 1e-15) → learning is too slow
- Start with alpha = 1e-9 for movie reviews (longer text = larger feature values)

**💡 Hints**:

- Use `np.log()` for logarithm
- Add small epsilon (1e-10) to avoid log(0): `np.log(h + 1e-10)`
- Print cost every 100 iterations to monitor training
- Cost should decrease over time!

**🎓 Concepts from Week 1 Material**:

- Logistic regression training (Section 8)
- Cost function (Section 10)
- Gradient descent algorithm (Section 11)

**🧪 Test your function:**

## 💡 Hints for Common Struggles

### "My cost is increasing!"

- Learning rate too high, try 1e-9 or 1e-10
- Check matrix shapes - broadcasting might be wrong
- Make sure you're using `-` (minus) in gradient update

### "My accuracy is stuck at 50%"

- Model is just guessing randomly
- Check if theta is updating (print it each iteration)
- Verify your gradient calculation
- Make sure y is in correct format (column vector)

### "I get numpy dimension errors"

- Print shapes of X, y, theta before operations
- Use `.reshape(-1, 1)` to ensure column vectors
- Remember: (m,3) @ (3,1) = (m,1) ✓

### "My preprocessing is too slow"

- Avoid nested loops where possible
- Use list comprehensions
- Compile regex patterns once outside loops

### "Unknown words cause crashes"

- Use `.get()` method: `freqs.get((word, label), 0)`
- Never use `freqs[(word, label)]` directly
