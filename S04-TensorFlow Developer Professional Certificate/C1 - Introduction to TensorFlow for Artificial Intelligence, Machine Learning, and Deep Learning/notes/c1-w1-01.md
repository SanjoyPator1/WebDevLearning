# 2. A Primer in Machine Learning

## Traditional Programming vs Machine Learning

### Traditional Programming Paradigm

Coding has been the foundation of development since the dawn of computing. Developers are used to creating applications by breaking down requirements into composable problems that can be coded against.

**Examples of Traditional Programming:**

- **Stock Analytics**: Write code to get values from data source → do calculation → return result
- **Game Development**: Define rules like "if ball hits brick, brick vanishes and ball rebounds" or "if ball falls off screen, player loses life"

**Traditional Programming Flow:**

```
Rules + Data → Answers
```

- Rules are expressed in programming language
- Data comes from various sources (local variables to databases)

### The Machine Learning Paradigm Shift

Machine learning **rearranges this diagram** completely:

```
Answers + Data → Rules
```

Instead of developers figuring out the rules, we:

- Get lots of examples of what we want to see
- Have the computer figure out the rules
- Let the machine infer patterns from the data

## Why Machine Learning is Powerful

### The Activity Recognition Example

Consider building a device that detects human activities. With traditional programming:

**Speed-Based Approach (Flawed):**

- Walking: `if speed < 4 mph`
- Running: `if speed >= 4 mph and < 8 mph`
- Biking: `if speed >= 8 mph`
- Golf: `???` (breaks the concept)

**Problems with Rule-Based Approach:**

- Speed alone is naive and insufficient
- People walk/run at different speeds uphill vs downhill
- Individual variations in speed
- Complex activities like golf don't fit speed categories
- Rules become impossible to define for many scenarios

### The Machine Learning Solution

Instead of trying to express problems as rules (often impossible), the new paradigm:

1. **Collect lots of examples** with labels
2. **Show the machine** what walking looks like, running looks like, biking looks like, golfing looks like
3. **Let the algorithm figure out** the specific patterns in each dataset that determine distinctiveness

## What Makes This Revolutionary

This programming paradigm is **more than just a new way of doing the same old thing**. It opens up new possibilities that were **infeasible to do before**.

The machine learning algorithm identifies patterns that humans couldn't easily define as rules, making previously impossible problems solvable.

# 3. The 'Hello World' of Neural Networks

## Pattern Recognition Challenge

Let's start with a simple pattern recognition exercise. Given these X and Y values:

| X   | Y   |
| --- | --- |
| -1  | -3  |
| 0   | -1  |
| 1   | 1   |
| 2   | 3   |
| 3   | 5   |
| 4   | 7   |

**Can you spot the pattern?**

The relationship is: $$Y = 2X - 1$$

### How Humans Solve This

1. Notice Y increases by 2 every time X increases by 1
2. Recognize the pattern looks like $Y = 2X +$ (something)
3. When $X = 0$ and $Y = -1$, deduce the "something" is $-1$
4. Test the formula $Y = 2X - 1$ with other values

**Congratulations! You just performed the basics of machine learning in your head.**

## Building Your First Neural Network

### What is a Neural Network?

A neural network is basically **a set of functions which can learn patterns**. The simplest possible neural network has only one neuron.

### Neural Network Architecture

```
Input (X) → [Single Neuron] → Output (Y)
     |                           |
 Single value              Predicted value
```

### The Complete Code Breakdown

```python
import tensorflow as tf
import numpy as np

# Define the model architecture
model = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),
    tf.keras.layers.Dense(units=1)
])

# Compile the model
model.compile(optimizer='sgd', loss='mean_squared_error')

# Prepare the data
xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)

# Train the model
model.fit(xs, ys, epochs=500)

# Make a prediction
print(model.predict([10.0]))
```

## Understanding Each Component

### 1. Model Architecture (`tf.keras.Sequential`)

**What it does:** Defines a neural network as a sequence of layers.

**Why we need it:** Provides the structure for our neural network. Sequential means layers are connected in order.

```python
model = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),          # Input layer: expects 1 number
    tf.keras.layers.Dense(units=1)       # Dense layer: 1 neuron
])
```

**Dense Layer Explained:**

- `Dense` = fully connected layer where each input connects to every neuron
- `units=1` = only one neuron in this layer
- This single neuron will learn the relationship $Y = 2X - 1$

### 2. Model Compilation (`model.compile`)

**What it does:** Configures the learning process by specifying:

```python
model.compile(optimizer='sgd', loss='mean_squared_error')
```

#### Loss Function: `mean_squared_error`

**Mathematical Formula:** $$\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2$$

Where:

- $y_i$ = actual value
- $\hat{y_i}$ = predicted value
- $n$ = number of samples

**Why we need it:** Measures how wrong our predictions are. Smaller loss = better predictions.

#### Optimizer: `sgd` (Stochastic Gradient Descent)

**What it does:** Adjusts the neuron's internal parameters to minimize loss.

**The Learning Process:**

1. Neural network makes a guess (e.g., $Y = 10X - 10$)
2. Loss function measures how bad the guess is
3. Optimizer figures out how to adjust parameters for a better guess
4. Repeat until **convergence** (accuracy approaches 100%)

### 3. Data Preparation (`numpy arrays`)

```python
xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)
```

**Why NumPy:** Makes data representation much easier, especially for mathematical operations that neural networks require.

### 4. Training (`model.fit`)

```python
model.fit(xs, ys, epochs=500)
```

**What happens during training:**

- `epochs=500` means the training loop runs 500 times
- Each epoch: Make guess → Measure error → Adjust parameters → Repeat

**The Training Loop:**

```
Initial guess: Y = random_weight * X + random_bias
↓
Calculate loss using MSE
↓
Optimizer adjusts weight and bias
↓
New guess: Y = updated_weight * X + updated_bias
↓
Repeat for 500 epochs
```

### 5. Prediction (`model.predict`)

```python
print(model.predict([10.0]))
```

**Expected vs Actual Results:**

- Mathematical answer: $Y = 2(10) - 1 = 19$
- Neural network prediction: ≈18.98 (close to 19, but not exact)

## Why Predictions Aren't Perfect

### Reason 1: Limited Training Data

- Only 6 data points used for training
- No guarantee the relationship $Y = 2X - 1$ holds for ALL possible values
- Neural network learns from limited examples

### Reason 2: Probabilistic Nature

Neural networks **deal in probabilities**, not certainties. The network calculates:

- "There's a very high probability that $Y = 19$ when $X = 10$"
- But it's not 100% certain, so it gives a realistic approximation

## Mathematical Insight

### What the Neuron Actually Learns

The single neuron learns two parameters:

- **Weight** ($w$): approximately 2
- **Bias** ($b$): approximately -1

**Final equation:** $$\hat{Y} = w \cdot X + b \approx 2X - 1$$

### Gradient Descent in Action

The optimizer adjusts these parameters using calculus:

$$w_{new} = w_{old} - \alpha \frac{\partial \text{Loss}}{\partial w}$$
$$b_{new} = b_{old} - \alpha \frac{\partial \text{Loss}}{\partial b}$$

Where $\alpha$ is the learning rate (controlled by SGD).

## Key Takeaways

1. **Neural networks learn patterns** through iterative guess-and-check
2. **TensorFlow/Keras handles the complex math** behind the scenes
3. **Even simple problems demonstrate core ML concepts**: loss functions, optimizers, training loops
4. **Results are probabilistic**, not deterministic like traditional programming
5. **More data generally leads to better predictions**

## Hands-On Implementation

This topic focuses on the practical implementation of our first neural network. We'll build the same $Y = 2X - 1$ pattern recognition model step by step.

## Step-by-Step Code Implementation

### Step 1: Import Required Libraries

```python
import tensorflow as tf
import numpy as np
```

**Purpose:**

- `tensorflow` provides the neural network framework
- `numpy` handles numerical arrays and mathematical operations

### Step 2: Define the Neural Network Architecture

```python
model = tf.keras.Sequential([
    tf.keras.Input(shape=(1,)),
    tf.keras.layers.Dense(units=1)
])
```

**What this creates:**

- A sequential model (layers connected in order)
- Input layer accepting single values
- One dense layer with one neuron

### Step 3: Compile the Model

```python
model.compile(optimizer='sgd', loss='mean_squared_error')
```

**Configuration:**

- **Optimizer:** SGD (Stochastic Gradient Descent) adjusts parameters
- **Loss Function:** MSE measures prediction accuracy

### Step 4: Prepare Training Data

```python
xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)
```

**Data represents:** The relationship $Y = 2X - 1$

### Step 5: Train the Model

```python
model.fit(xs, ys, epochs=500)
```

**Training process:** Model runs 500 learning cycles (epochs)

## Understanding the Training Process

### What Happens During Training

**Initial State:**

- Loss is high (neural network's guesses are poor)
- Model starts with random weights and bias

**During Each Epoch:**

1. Model makes predictions for all X values
2. Loss function calculates error: $\text{MSE} = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2$
3. Optimizer adjusts weights to reduce loss
4. Process repeats

**Observing Progress:**

- Watch the loss value decrease epoch by epoch
- Lower loss = better pattern recognition
- After 500 epochs, loss becomes very small

### Step 6: Make Predictions

```python
print(model.predict([10.0]))
```

**Expected vs Actual:**

- Mathematical answer: $Y = 2(10) - 1 = 19$
- Model prediction: ≈18.98

## Key Learning Points

### Why the Prediction Isn't Exactly 19

**Reason 1: Limited Training Data**

- Only 6 data points used
- Neural network generalizes from limited examples
- Uncertainty exists for unseen values

**Reason 2: Probabilistic Nature**

- Neural networks work with probabilities
- Model calculates likelihood, not certainty
- Realistic approximations rather than perfect answers

### Practical Observations

**Loss Behavior:**

- Starts high (poor initial guesses)
- Decreases progressively with each epoch
- Eventually converges to very small value

**Model Learning:**

- Gradually discovers the $Y = 2X - 1$ relationship
- Adjusts internal parameters (weight ≈ 2, bias ≈ -1)
- Becomes increasingly accurate with training
